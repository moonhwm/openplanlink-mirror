# 华为云 Flexus X 实例 CPU 算力榨取设想卡 · 2026-10-06

档号：RESEARCH-KIMI-2026-1006-02 · 幻16Kimi席调研产出
conf 声明：华为云官网对 X 实例单价明示「以控制台为准」，本卡所有价格数字均 conf=unverified 或为标注推断，**不得直接引用为报价**。

## 一、实例特性（机制层，conf=high）

- 柔性算力机（X86 + 鲲鹏 ARM 两种底），支持自定义 vCPU/内存配比（最高 3:1，1 核 1G 粒度调整）。
- 基础/性能两种模式切换（性能模式突发更高，计费差异以控制台为准）。
- **按需计费关机不计 vCPU/内存费**——这是「充分榨取」的基石：常驻服务关机即停租，夜间批跑按次点火。

## 二、价格现状（全部 conf=unverified）

- 官网无公开单价页；检索到的 338/288/29 元均为 2024–2025 历史促销截图，已过期口径。
- 推断档（明确标注为推断）：包年 4 核 8G 日常档约 300–900 元/年；EIP 流量单价未查到可靠数。
- **行动建议**：W1 周先开一台按需小实例 24h 实测账单校准，再决定包周期档——实测数据 > 一切网络传言。

## 三、榨取负载清单（7 项，常驻组合均值 <0.5 核 / <2 GB）

| 负载 | 资源占用 | 排期建议 |
|---|---|---|
| CI runner（接私仓超额分钟） | 构建期 1–2 核脉冲 | 事件驱动，随触发点火 |
| 静态站/文档托管（A2A 面板） | ≈0.1 核常驻 | 7×24 常驻 |
| A2A 消息总线中继 API | ≈0.2 核常驻 | 7×24 常驻 |
| 夜间批处理（漂移监测轮询） | 0.5–1 核 × 2h | 每日 02:00–04:00 点火 |
| 隧道端点（内网穿透备用） | ≈0.1 核 | 按需 |
| 轻量缓存/索引库 | ≈0.2 核 | 常驻或随批跑 |
| 节点健康监控探针 | 可忽略 | 常驻 |

## 四、预算三档组合

- **<50 元/月**：纯夜间批跑按需（关机不计费），零常驻——适合当前验证期。
- **<100 元/月**：2 核 4G 包月小锚点（静态站＋总线中继常驻，批跑叠加）。
- **<200 元/月**：4 核 8G 满榨取（上表 7 项全装，余量给 CI 脉冲）。

## 五、排期（W1–W4）

- W1：开按需实例 24h 实测，校准账单模型（关机计费、EIP、流量）。
- W2：上常驻两件套（静态站＋中继 API），观测 7 天均值。
- W3：接入夜间批跑（漂移监测从本机迁云，本机减负）。
- W4：按实测账单在 <50/<100/<200 三档中固化，出《榨取决算》。

## 六、未能核实项（诚实清单）

- 当前按需/包周期单价、区域价差、X86 vs 鲲鹏同价与否、EIP 流量单价、热变配支持——均需控制台实测，无任何可引用数。
