## 4. 概念边界与 OpenPlanLink 的有限应用

主人道德与奴隶道德首先关乎评价如何形成：前者以自身充盈、尊贵和肯定为起点，后者在受阻的行动与想象的报复中把敌人的“好”重新定为“恶”。它们仍有社会统治关系的历史语境，不能脱离这一点只谈个人心态；也不能按照收入、职级、政府权限、平台角色或是否批评项目，直接给现实个人归类。§260 提醒二者可以共存，因而二元人物评分并无文本支持。

怨恨并非任何不满、记忆、反对意见或制度批评。I§10 所分析的是无法直接行动的报复情绪如何组织持续的评价反转。就项目研究而言，应检查论证是否以他者为唯一负面支点，并允许比较别的解释；不能通过贴“怨恨”标签跳过证据、否决异议或心理诊断参与者。这里是由阅读提出的研究问题，尚非已经验证的社会科学测量指标。

价值重估需要区分旧价值秩序的反转、对价值本身的批判，以及未来价值的创造。I§10 的反转也能创造价值，不能把所有“创新”都算作尼采赞许；§211 则将哲学家的任务连到人的方向与目的。OpenPlanLink 的提案、协作与审计功能至多提供讨论价值的制度条件；有写权限、行政权力、收益、声望或技术控制能力，均不足以证明哲学意义上的价值创造。

“自觉自决”在这里先作为项目的操作性用语：参与者能识别目标、说明理由、承担承诺、反思既有评价。它不自动等同于尼采的主权个体或康德的自主。康德的普遍立法要求与尼采的等级和价值批判存在理论张力，需要比较，不能用中文“自主”一词抹平。II§2 的长期承诺可帮助提出责任研究问题，I§13 又要求谨慎对待一个脱离行动与形成史、无限任意选择的自我。

## 5. 《权力意志》的文献地位

“权力意志”作为概念，已出现在尼采生前出版的著作，例如本轮所读 JGB §211；这与后来题为《权力意志》的编排书不是一回事。Nietzsche Source 的手稿项目明确指出后者并非尼采完成的一本书。研究应将流通版本视为身后遗稿的编辑编纂，注明编者、编排版本，逐条回查遗稿年份、片段号、KGW/KSA 与手稿定位；不能把编排顺序当作作者最后系统，也不能因为编纂问题就说所有片段均为伪造。[Nietzsche Source 遗稿影印项目说明](https://doc.nietzschesource.org/en/dfga)

本轮没有下载或精读《权力意志》现代译本，没有完成流通条目与 Nachlass 编号的对照。Nietzsche Source 提供的数字版整体声明采用 CC BY-NC-ND 4.0，并要求准确来源链接；公开可读不等于无限商业再利用。[Nietzsche Source 权利说明](https://doc.nietzschesource.org/en/rights)
