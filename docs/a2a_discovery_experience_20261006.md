# 节点发现、产学研接入与迁移追溯使用记录

现有回环服务已经运行，本轮直接读取其 Agent Card 与健康页，并实施有限范围的发现工具。卡片基本字段和声明版本可读；这些证据只支持发现记录。标准协议的方法调用、授权范围及独立节点确认仍需分别验证。共享 HMAC 的成功应答不能替代机构身份或多方签收。

产学研协同以具体任务连接需求提出、技术验证、实施反馈三个工作环节。节点登记应关联任务目标、能力证明、数据范围、环境及成果验收标准；参与单位和责任人没有实际登记回执时保留待核状态。已有协作数据库可提供结构参考，本轮保持只读。

用户指定的掘金文章可取得正文，B 站短链及对应 BV 页面未取得内容；检索出现同名但不同 BV 的视频，不能据此绑定为用户给定来源。文章中的性能数字按作者陈述处理，不用于填报本项目效能。硬件互联、模型推理优化和应用 A2A 协作分层评估。

华为官方介绍的灵衢架构涉及跨部件互联与算力协同，本项目据此提出减少资料重复传输、将有成果的 CPU 任务批量执行、记录通信等待的实施方向；这是本项目推论，不宣称已部署该硬件。vLLM 官方文档将推测解码的目标场景界定为中低 QPS、内存受限工作负载，不能把所有任务都当作固定加速倍数。PagedAttention 论文可供显存管理研究，不能直接替代华为云 X CPU 实测。

迁移追溯需节点操作日志、桌面快照、配置基线、责任人及处置期限，并以主控台和安全运营中心的实际交接回执闭环。未取得批准的策略基线时，新增或变化的进程不能直接判为违规；正常服务、VPN、自启动配置及业务链路均需保留。主控台地址、SOC 连接、责任人映射和留存规则尚未核验，不能声称已推送或已经复核通过。

本轮 WPS 元数据版本更新至 61，ima 项目知识库计数更新至 3,991。本地源资料仅主 DOCX 字节变化，已触发新加密捕获；其他资料和旧失败证据保留。定期触发与实际完成的检查分别记录，合并处理同一执行期间的重复触发，不追造过去每个时间点的观测。
