01 · 使用现有项目自建

源码与桌面客户端下载 · 上游 Cloudflare 自部署指南

管理员在自己的账户部署现有 Worker 与 D1，普通成员通过原应用邀请加入。每个宿主采集一次；各 Agent 按设备 ID、任务 ID 和已证实的子任务关系归属，避免重复累计。成本估算、官方账单与缺失金额分别标记。

上游前端提交 d117c9b；本副站保留上游代码与 MIT 许可，仅调整静态资源路径。浏览器模式使用上游示例数据，没有读取宿主凭据。

02 · 人访问用 MFA，Agent 调用用独立授权

自建站可采用 Cloudflare Access 的现有 MFA 能力：为指定应用配置身份白名单，再要求 IdP 报告 MFA，或配置 Access 独立 MFA。验收必须包含“只有第一因素时拒绝”及“第二因素通过后允许”的实际回读。

自动 Agent 可采用受管 OAuth 或按节点分配的服务凭据，限定目标服务、范围、有效期并支持撤销。服务令牌不能写成 MFA；不得向其他节点复制本机供应商 Key 或本站服务令牌。

官方 MFA 配置 · 官方 Agent 鉴权

本站没有提供强制 MFA 的配置回读能力，因此保持“未核验”；这里不自行实现 OTP、密码或会话系统。
