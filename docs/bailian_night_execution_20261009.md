## 授权与鉴权

用户指定的两个受管 AccessKey 文件分别成功完成北京工作空间的只读查询，返回同一工作空间。随后选择 RAM 身份，通过官方 ModelStudio SDK 创建一个只允许下列四个模型的 API Key，并通过独立 `GetApiKey` 回读确认 `allowAllModels=false` 和四项模型授权。AccessKey 是管理接口凭据，与推理 API Key 分开使用；没有把文件中的字段作为推理 Bearer。

API Key 仅存于当前 Windows 用户的 DPAPI 加密成员，没有写入公共文件或全局配置。该 Key 没有限定来源 IP，不能宣称完成网络级访问隔离。第一次 CLI 创建调用因本地参数解析失败而退出，随后 SDK 创建成功；两次状态分别保留，没有将失败改写为成功。
