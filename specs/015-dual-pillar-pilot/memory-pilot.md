## 范围和现有模块

`tools/memory_tier_pilot.py` 复用 `tools/cas_store.py` 的 SHA-256 CAS 和 gzip 原件保存；复用 `memory_sample_audit.memory_risk` 的缺失证据状态，不调用主机采样函数。保留 `event_driven.py` 的 type/source/payload/key 事件语义，独立 SQLite 账本补足载荷冲突检查和成功后消费语义。现有事件骨架全局 `_SEEN` 在处理前标记且未比对载荷，因此试点不调用其 emit，不改写它。

原文按完整 UTF-8 字节取 SHA-256。同内容多个 reference_id 共用一份原件，每个引用仍指向完整的 64 位原件哈希。换行和字符不被摘要、归一化或删除。读取原件重新校验内容哈希；报告使用 SQLite 读快照并逐件回读校验，原件缺失、损坏或大小异常时拒绝报告；同 reference_id 替换原件拒绝。热温冷是逻辑建议，没有物理迁移、淘汰或原文删除。

## 可配置规则

所有访问数来自已成功消费的访问事件；默认滚动窗口 168 小时。事件中含带时区的 occurred_at_utc；报告显式传入评估时间。先判热层，再温层，否则冷层：

| 层级 | 默认需求规则 | 默认请求延迟预算规则 |
|---|---|---|
| hot | 窗口访问数 ≥ 3 且最近访问 ≤ 24 小时 | 预算 ≤ 20 ms |
| warm | 窗口访问数 ≥ 1 且最近访问 ≤ 168 小时 | 预算 ≤ 200 ms |
| cold | 不满足以上需求 | 未给预算或预算高于温层阈值 |

需求规则与预算规则任一满足即可进入该层。预算是调用方请求的 SLA，不是测得延迟；observed_latency_ms 始终 null。没有访问事件代表该试点观察窗口中尚无访问证据，不能据此判断私有源真实热度。报告遇到未来创建/访问证据拒绝出具。阈值、访问窗口和每层容量都可配置，阈值未获批为生产策略。

容量用去重后原件逻辑字节计数；未提供容量时状态 unknown。达到 warning_ratio（默认 0.8，包括边界）预警，大于容量标记 exceeded。预警只输出报告，不自动移层、删除或扩容。该逻辑字节容量不等于 RAM、磁盘实际 gzip 占用，也不包括 SQLite 元数据。

## 幂等、失败和保留

事件指纹 = SHA-256(规范 JSON `[type, source, payload]`)。相同 event_id、相同规范载荷返回 duplicate 并复用已保存结果；JSON 对象键顺序不影响指纹。相同 ID 不同载荷、类型或来源抛 EventConflict，原件/访问数/账本不改变。payload 中时间戳变化同样属于冲突。

BEGIN IMMEDIATE 序列化元数据事务；仅操作成功才写 events 表并一起提交。失败回滚，不提前消耗事件 ID。重复事件重启后仍可识别。CAS 原件文件及其现有独立数据库不属于同一个 SQLite 事务，进程崩溃可能留下孤立原件；不自动清理孤立原件，后续需审计恢复。此试点不是跨系统事务、分布式锁或云存储一致性证明。

## 成本口径

报告对比每个引用都复制原文的 baseline 字节与去重后唯一原件字节，同时给出唯一原件全热层的估算基线。显式传入三个合成单价（单位 synthetic_units / GiB-month）才估算每月逻辑存储成本；不提供则 estimated_total 为 null。演示单价 hot=10、warm=3、cold=1 全部人工设置，不能当作任何云厂商报价。

actual_cloud_bill、billing_evidence、CPU、峰值内存、耗时、吞吐、排队时间、cloud_cost 与 host_identity 全部 null。没有实测的值不得填 0。成本不包含计算、内存、请求、外发、副本、压缩、元数据和排队费用。人工单价乘逻辑字节的结果不证明降本；真实账单和资源/资金申请另走审批链，未经批准不得触发资源变更或对外承诺。
