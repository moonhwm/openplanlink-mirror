# 节点发现最小实施计划

前序接入成果已推送并回读确认。新增成果完成后继续使用现有增量上传门禁、受管密钥和非强制推送流程。

使用 Python 标准库实现只读 CLI。连接以操作者提供的 origin 为唯一来源，固定两个 GET 路径，直接使用 `http.client`；不改变代理或 VPN 设置，不读取浏览器认证数据。HTTPS 使用系统证书验证，不自动重定向。

响应上限 64 KiB，单请求默认 5 秒。严格 JSON 对象解析后，只输出有限版本值、字段检查结果和数量。卡片 description、examples、端点 URL、认证 URL 及其他任意文本不回显。

CLI 输出独立 JSON。发现成功只提升至 card_observed；身份、认证、标准方法和席位签收由后续对应验证器给出，不在发现器中凭声明推断。观测失效时间用于提醒重新探测，不能把未认证探测变成认证心跳。

回环实测使用已经运行的现有服务。信箱接口有第二因子要求，本轮不尝试从密钥文件推导或绕过该要求，不拉取其他席位信箱。

远端接入、云端计算及资料上传均等待实际环境定位或账户回执。已有用户授权继续有效；缺失账户信息按事实记录，不重复索要已授予的操作权限。
