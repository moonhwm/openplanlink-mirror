# 夜间排期与执行就绪判定规格

状态：本规格只覆盖整体 A2A 分布式夜间协同及华为云 X 实际执行要求中的纯计算排期阶段。后续授权验证、任务下发、真实云作业、账单和独立席位验收仍有接口缺口。

## 输入基线

2026-10-06 读取受控 R8 夜间排期证据及公开的 `docs/cloud_connections_status_20261006.json`。该记录的华为云已核验作业数为 0，实例和授权配置引用缺失；已有本节点 HMAC 验证与五席未签名入队记录，独立席位确认数为 0。上述历史观察不能变成本轮有效签名或执行回执。

## 可验收需求

- N1：仅用 Python 标准库；显式输入带时区的 ISO 8601 时间。北京时间使用固定 UTC+08:00，UTC 比较采用 aware datetime；拒绝无时区时间。计算和 CLI 不访问网络、不读取凭据、不启动进程、不创建自动化、不发送任务。
- N2：暂行运维窗口为北京时间 `[23:00, 次日08:00)`，包含起点、排除终点。默认收尾缓冲为 30 分钟，这是实现的保守暂行参数，不是用户指定的具体分钟数；允许以 1—180 分钟显式调整。进入收尾后停止扩展计划并给出保存成果及回执的动作。窗口外不给出新任务排期资格。
- N3：分别计算 Qoder 普通产品 `[22:00, 次日08:00)` 与 Service Account `[01:00,07:00)`。账户类型未知时输出两种可能而不给当前账户折扣结论。Qwen3.8-Max 标准 Credits 倍率 0.5x、错峰 0.2x、相对标准价 0.4；这是计价规则，不是费用实测，也不切换模型。
- N4：DeepSeek 高峰为 UTC `[01:00,04:00)` 与 `[06:00,10:00)`，仅周一至周五且排除中国公共假日，其余低峰。UTC 工作日内高峰时段，未取得覆盖该日期的供应商适用公共假日证据时返回 unknown。周末或高峰时段之外的低峰无需推定某日期为假日。拒绝证券交易日历等替代日历。低峰对高峰比价 0.5 仅为规则引用。
- N5：身份绑定、实例授权、节点签名回执、标准方法验收和独立席位确认是分开的输入。每份声明需要 SHA-256 受控引用、验证器引用、任务范围匹配、主体匹配和 `[issued_at, expires_at)` 有效期。缺失、未验证、未生效、过期、范围或主体不符均保持阻断。必需席位清单非空且去重；确认来自该清单，自己或节点的身份不能充当独立席位。共享 HMAC 不能作为独立席位签名或 PQC 证明。
- N6：本组件不实现可信验证器或信任登记，输入 `verification_status=verified` 只是外部验证声明。即使所有声明完整，也只能输出“候选就绪，待独立验证”；本纯计算入口的 `eligible_for_task_dispatch`、`cryptographic_verification_performed`、`pqc_verified` 和 `peer_consensus_verified` 始终 false。摘要和自填布尔值不能获得实际下发许可。后续整体项目仍应接入受信验证器和真实执行器，本规格不把禁止实际执行作为整体项目验收目标。
- N7：并发参考有效成果吞吐量和健康。无待处理任务时建议空闲；不做无效 CPU 计算或填充内存。只有两份当前、同实例、同任务范围、同负载摘要及同成果单位口径的华为云样本声明均有运行回执引用，且有限的候选有效吞吐提高至少 5%、失败率不升、P95 延迟不超过基线 110%、CPU 不超过 90%、内存不超过 80% 时，才建议在独立验证后考虑该候选；不扩大到未经观测的并发值。实例、scope_sha256、workload_sha256 和 units_kind 均须匹配当前 task，缺失或错配保持当前并发。本机样本不能代替华为云样本。收尾阶段始终暂停扩展。
- N8：输入最大 64 KiB，最多 32 个独立席位，严格 JSON 对象、无重复键、无非有限数值、无未知字段。只有有限枚举、数值、时间和 64 位小写 SHA-256 引用进入输入契约，不接受原文、用户路径、MAC、认证材料或任意说明。输出白名单只含时窗、固定状态、固定原因码、计数和规则常量；不回显输入路径、摘要引用或任意错误内容。可选输出文件独占创建，禁止覆盖。
- N9：本轮不能将输入样本声明标为实测。输出本机与华为云状态分开，华为云已验证作业数为 0，CPU、内存、耗时、吞吐、排队时间、费用和执行回执保持 null。真实执行与费用须由后续独立核验接口补证。
- N10：供应商规则快照必须有显式观察下界及失效时刻。本次以实际 UTC 时钟回读建立保守记录下界 2026-10-06 06:28:30 北京时间，暂行有效 24 小时，区间 `[2026-10-06T06:28:30+08:00,2026-10-07T06:28:30+08:00)`；这不是供应商承诺的有效期。早于观察下界、到达失效时刻或更晚均输出 needs_revalidation，Qoder 当前时窗结论为 null、优惠候选 false，DeepSeek 不判当前低峰或高峰。后续须重新核对官方规则并更新受控快照，不能用调用者自填 verified 无限延长。
