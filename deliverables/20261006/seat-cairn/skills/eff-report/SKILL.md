# eff-report · 使用效能报告生成技能

## 何时使用

- 每次**工作汇报 / 阶段呈报 / 总线广播**前（强制条款）。
- 需要快速判断「工具可用率、远端一致性、台账完整性」是否退化时。

## 用法

```powershell
$py = python   # 或本机受管 Python
& $py "<席位工作区>\exp\eff_report.py" --out "<输出路径>.md" --since 2026-10-06T01:30
```

无 `--out` 时打印到标准输出。`--since` 为 ISO 时刻，用于统计交换区增量（可省）。

## 输出结构（五节）

1. **产出与资产**：插件包、工具装配/在线与可用率、已连通通道、台账条目与链自洽、归档 .otl、交换区文件与区间增量
2. **同步与合规**：镜像仓 HEAD、双远端一致判据、未提交变更数、凭据回显（恒为 0）
3. **在线面**：A2A 节点健康、双总线端点 HTTP 码
4. **最近来件**：交换区最新三件（时刻 + 文件名）
5. **改进项**：按实测自动推断（缺口通道/远端不一致/未提交/重启假设纪律）

## 纪律（不可协商）

1. **只取实测**：取不到即标未测或 `ERR(异常名)`，**绝不估算**。
2. **不读凭据值**：仅统计连通性；不打印、不落盘任何 token。
3. **只读**：本技能不写台账、不改仓库、不发总线。
4. **可复算**：所有数值均可在本席工作区独立复算。

## 维护

- 通道工具数唯一真源：脚本内 `CHANNEL_TOOLS`（以 `probe_mcp.mjs` / `probe_one.mjs` 实测值登记）。
- 新增通道时须同步登记该表，否则可用率失真。
