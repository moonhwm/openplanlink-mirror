## 三、规格选型设想（按负载画像配柔性配比）

| 场景 | 设想规格 | 模式 | 配比逻辑 |
|------|---------|------|---------|
| 常驻轻载（L5+心跳+watchdog） | 2 vCPU / 4 GiB 或 2/2 | 基础模式 | 省钱保活，按需关机策略待核 |
| 压测/评审冲刺（L1/L2） | 8~16 vCPU / 16~32 GiB（2:1）| 性能模式 | CPU 密集+稳定 QoS；热变配临时升配 |
| 数据管道/ASR 夜批（L3/L4） | 4 vCPU / 8 GiB（1:2）夜间热升 8/16 | 基础→性能 | 夜场窗口榨取，日场降回 |
| 大促发式全量（L1~L6 并发） | 32 vCPU / 64 GiB（2:1）| 性能模式 | 周末/假日窗口，跑完即降 |

## 四、排期（榨取窗口）

| 窗口 | 时段（北京时间） | 动作 |
|------|----------------|------|
| 日场 | 09:00~23:00 | 常驻轻载档；仅事件驱动任务（CI/心跳/监听） |
| 夜场 | 23:00~07:00 | 升配冲刺：L1 压测 + L3 转写队列 + L4 管道满载 |
| 周末窗 | 周六 20:00~周日 08:00 | 全量大压测 + 归档上云（百度云盘 16.5TB 目标） |
| 熔断 | 任意时刻 | 费用日报超阈或机主指令 → 降配/关机，留痕通告 |

## 五、安全与协同纪律

1. **凭据主权**：实例访问用 IAM 临时凭证或密钥托管下发，明文永不落盘/入总线/入镜像仓库。
2. **VPN 与进程保护**：X 实例流量不绕行本机 Zodacess 路由；本席进程（PID 41000 等他席服务）零干扰；实例 watchdog 自修复，失联自动上报 A2A 总线。
3. **A2A 节点化**：X 实例作为 A2A 网络首个云端计算节点，注册表候选挂 Neon `agent-db`（S3 灵感③），节点发现协议沿用 heartbeat+broadcast（S7 输入）。
4. **KPI 台账**：每元产出（评测跑批数/转写时长/构建次数）日报，空转即降配——榨取≠浪费。
