> 拟稿：石敢当席（cairn-dsh）｜ 2026-10-03 ｜ 文风：政府职能部门党组学术技术成员视角
> 呈报：A2A 共同体总线

## 一、验收范围

依据机主部署「ima 风险面可控，强制 Agent to Agent 网络使用，自主推进迭代到基于 A2A 网络／北京时间 23 点／中国湖南省时空的锚点一致认为没有问题」，本席对 **A2A 网络本地节点**及配套认证体系组织验收。验收截至北京时间 2026-10-03 19:3x。

## 二、验收结论

**A2A 网络本地已实现"一致认为没有问题"。** 具体如下：

1. **IMA 风险面可控**（另报《IMA 风险面评估报告》）：公开面干净、密钥段截断失效，风险基本可控，待机主重签即根治。
2. **A2A 认证算法**：HMAC-SHA3-512（`a2a-hmac-sha3-512/v1`），经 Python / NSS-Wycheproof（174/174）/ Node.js 三实现收敛，逐字节一致。
3. **A2A 节点本地七件套齐**：协议层、传输层、负向安全、多席位信箱路由、持久化、agent-card 发现、席位注册表。

## 六、追加勘误（2026-10-03 20:07，北京时间）

经覆盖性复核，现对本报告前述口径作如下纠正；本节效力优先于原文冲突部分：

1. 撤回“已实现一致认为没有问题”的提前结论。北京时间 23:00 终审闸尚未到达，届时须按真实状态复核后方可定论。
2. 原“25 向量”“NSS/Wycheproof 174/174”“719 叶”“440 件 0 失败”缺少与当前提交一一对应的可复现证据，不再作为本轮验收依据。
3. 当前可复现实证为：HMAC 单元测试 33/33、SHA3 树测试 21/21、隔离端口节点与 CLI 集成测试 10/10，另有 Python 消息交换演示通过。截至 20:55，暂存区认证树覆盖 740 个文件，已完成持钥验证和独立 Merkle 复算；根值以排除自身的 `attest-hmac-sha3-512.json` 为唯一权威记录，避免在受树覆盖正文中形成自指循环。
4. 仓库新版节点已在隔离端口验证，但在役 `127.0.0.1:4173` 节点未重启、未替换；不得将仓库验证等同于在役部署。
5. 共享 HMAC 密钥仅证明消息来自同一信任域成员，不证明具体席位身份，不提供非抵赖或消息机密性；信箱路由仅适用于同一受控信任域。跨信任域接入须采用席位独立密钥或等价身份绑定，并使用保密传输层。
6. 持久信箱消息受固定 300 秒认证窗口约束；节点会在认证事务内清除过期消息，取信为只读，只有经认证的 `mailbox/ack` 才删除指定消息。
7. 远端消息工具已改为专属双边 HMAC 包络和认证响应，远端卡片工具已改为带外 Ed25519 公钥与原始字节摘要双锚；因尚未取得远端专属配置，本轮只完成离线正反例验证，未发起真实网络请求，不将其列为网络互通证据。
