# 债权信息折扣期全链路分析

以债权在当前时点的**可回收现值**为核心，把从形成到最终回收的全过程拆成流转环节，逐环节评估价值损耗（折扣因子 D1-D6），连乘得出**折扣后真实价值**（悲观/中性/乐观三情景）。

```
债权形成 → 判决确认 → 执行申请 → 财产查控 → 清偿/分配 → 实际回收
  [100%]    [D1]      [D2]       [D3]       [D4]        [D5×D6]
```

## 六大折扣因子（概览）

| 因子 | 含义 | 详细评估矩阵 |
|---|---|---|
| D1 判决确认折扣 | 债权是否获生效判决支持 | [reference.md](reference.md) §1 |
| D2 执行折扣 | 债务人实际偿债能力 | 同上 §2 |
| D3 资产折扣 | 可执行资产的变现价值 | 同上 §3 |
| D4 顺位折扣 | 清偿顺序中的优先级 | 同上 §4 |
| D5 时间价值折扣 | 资金占用时间成本（公式 1/(1+r)^n 复算） | 同上 §5 |
| D6 不确定性折扣 | 未来回收的不可预见风险 | 同上 §6 |

🔴 所有因子区间均为**经验估计值**（无公开权威出处），使用时按本地司法实践与实案数据校准，并在报告中逐因子写明取档理由——不得把区间端点当作精确预测。

## 分析流程（八步）

1. **债权清单梳理**：逐笔提取债务人、本金、案号、判决金额与时间、执行进展、债务人资产与涉诉状况。
2. **逐笔全链路折扣分析**：按下表逐环节连乘评估。

```markdown
| 链路节点 | 金额 | 折扣因子 | 折扣后价值 | 说明 |
|:---|:---|:---|:---|:---|
| ① 原始债权（本金） | [金额] | 100% | [金额] | [形成过程] |
| ② 判决确认金额 | [金额] | ×[D1] | [金额] | [判决支持情况] |
| ③ 含后续利息/违约金（名义） | [金额] | 100%（名义） | [金额] | [持续计算至当前] |
| ④ 执行折扣 | — | ×[D2] | [金额] | [偿债能力取档理由] |
| ⑤ 资产折扣 | — | ×[D3] | [金额] | [资产变现取档理由] |
| ⑥ 顺位折扣 | — | ×[D4] | [金额] | [清偿顺位] |
| ⑦ 时间价值折扣 | — | ×[D5] | [金额] | [1/(1+r)^n 复算值] |
| ⑧ 不确定性折扣 | — | ×[D6] | [终值] | [程序进展] |
```

每环节给出算式；三情景取档：悲观=各因子区间下限连乘，中性=中值连乘，乐观=上限连乘（方法与 scripts/discount_calculator.py 一致）。
3. **折扣因子评估**：照 [reference.md](reference.md) 的逐因子矩阵取档，写明理由。
4. **组合折扣汇总**：逐笔汇总三情景估值与折扣率，算合计。
5. **Waterfall 分析**：按**折扣因子逐环节**绘制价值损耗瀑布（每级扣减=上级余额−本级余额，末级余额+累计扣减=名义总额，必须勾稽）。
6. **质量评级**：A<20% / B 20-40% / C 40-60% / D 60-80% / E>80%（折扣率）。
7. **财务影响评估**：账面 vs 折扣后公允价值、减值金额与比例、关键比率（回收率/坏账率/债权与减值对注册资本倍数/集中度 HHI）。
8. **处置建议**：P0/P1/P2 分级行动清单 + 折扣优化策略 + 财务建议（标注「待管理层/会计师确认」；涉及金额预期必须给测算依据，无依据不写具体数）。

## 输出要求

1. Markdown 报告，表格呈现折扣分析数据，ASCII 图展示 waterfall
2. 金额精确到元，百分比保留一位小数，🔴🟡🟢 标识风险等级
3. 保存到 output/ 目录
4. 🔴 示例与真实案件数据**一律脱敏**（公司→代号、自然人→甲乙、案号→(20XX)XX 字第 XXX 号）；用户提供的未脱敏材料只在用户授权的输出中保留
