# 债权信息折扣期全链路分析 — 详细参考文档

## 一、折扣因子详细评估标准

> 🔴 本文档全部折扣区间与清偿率为**经验估计值**（无公开权威出处），取自实务经验归纳；使用时须按本地司法实践、行业数据与实案证据校准，并在报告中逐因子写明取档理由。不得作为精确预测或对外引用的统计数据。

### 1.1 D1 判决确认折扣 — 详细标准

#### 评估要点

判决确认折扣评估债权信息是否获得生效判决的完全支持。

#### 评估矩阵

| 判决结果 | 折扣因子 | 适用条件 |
|:---|:---|:---|
| 全额支持 | 100% | 判决全额支持本金、利息、违约金 |
| 本金全额、利息部分支持 | 90%-95% | 本金全额支持，利息/违约金被调减 |
| 部分支持 | 50%-90% | 仅支持部分债权信息 |
| 驳回 | 0% | 判决驳回全部诉讼请求 |
| 调解结案 | 70%-95% | 调解金额与判决金额的比例 |
| 未判决（诉讼中） | 60%-80% | 根据案件胜诉概率评估 |
| 未起诉 | 50%-70% | 债权信息尚未经过司法确认 |

#### 特殊情形

- **分段利率支持**：如判决对不同时间段适用不同利率（如2020.8.20前按年利率24%，之后按15.4%），需分段计算
- **违约金调整**：如判决将违约金从合同约定调减至法定上限，折扣因子按调整后的比例计算
- **以物抵债驳回**：如主张的以物抵债被驳回（如未办理抵押登记），该部分债权信息折扣为100%

### 1.2 D2 执行折扣 — 详细标准

#### 债务人偿债能力评估矩阵

| 评估维度 | 优秀(80-100%) | 一般(40-70%) | 差(15-40%) | 极差(0-15%) |
|:---|:---|:---|:---|:---|
| 经营状态 | 正常经营、盈利 | 经营困难但持续 | 停业/半停业 | 破产/注销 |
| 资产覆盖 | 资产>债务×2 | 资产≈债务 | 资产<债务×50% | 资产≈0 |
| 涉诉情况 | 无重大诉讼 | 1-2件小额诉讼 | 多件大额诉讼 | 失信被执行人 |
| 现金流 | 充裕 | 紧张但可维持 | 严重不足 | 完全断裂 |
| 对外担保 | 无 | 少量 | 大量 | 巨额连带 |

#### 特殊情形处理

**破产重整**：
- 重整成功概率评估：关注重整投资人招募情况、保证金金额、投资方案要求
- 普通债权清偿率参考：约5%-30%（经验估计区间，须以本案管理人披露与同类重整案例校准）
- 保全措施影响：根据《企业破产法》第19条，保全措施应当解除
- 清偿顺位：普通债权劣后于破产费用、职工债权、税款、有财产担保债权

**失信被执行人**：
- 查询中国执行信息公开网确认失信状态
- 评估是否存在"终本"（终结本次执行程序）情况
- 评估是否存在限制高消费措施

**关联企业群**：
- 穿透核查债务人关联企业
- 评估是否存在资产转移、逃废债行为
- 评估关联企业的连带担保责任

### 1.3 D3 资产折扣 — 详细标准

#### 各类资产折扣率

| 资产类型 | 折扣因子 | 评估要点 |
|:---|:---|:---|
| 现金/银行存款 | 95%-100% | 是否已被冻结 |
| 应收账款 | 50%-80% | 账龄、债务人信用 |
| 存货 | 20%-50% | 变现难度、折旧 |
| 设备 | 20%-50% | 折旧、专用性 |
| 房产（有产权证、可交易） | 60%-80% | 位置、市场价值 |
| 房产（无预售许可等瑕疵） | 20%-40% | 变现困难 |
| 土地使用权（正常） | 50%-70% | 位置、用途、剩余年限 |
| 土地使用权（被收回） | 0% | 核心资产灭失 |
| 股权（正常企业） | 30%-60% | 企业净资产、盈利能力 |
| 股权（空壳/停业企业） | 0%-5% | 无实际价值 |
| 知识产权 | 10%-40% | 变现难度极高 |
| 车辆 | 30%-60% | 折旧、变现 |

#### 资产优先级评估

当存在多个债权人时，需评估资产的优先受偿情况：

| 优先权类型 | 说明 | 对债权人的影响 |
|:---|:---|:---|
| 抵押权 | 已办理抵押登记 | 抵押权人优先受偿 |
| 质押权 | 已办理质押登记 | 质押权人优先受偿 |
| 留置权 | 法定留置 | 留置权人优先受偿 |
| 建设工程价款优先权 | 法定优先 | 承包人优先受偿 |
| 首封权 | 首先查封 | 在执行分配中有一定优势 |

### 1.4 D4 顺位折扣 — 详细标准

#### 破产清偿顺序

根据《企业破产法》第113条：

| 顺位 | 债权类型 | 典型清偿率 |
|:---|:---|:---|
| 最优先 | 破产费用和共益债务 | 100% |
| 第一顺位 | 职工债权（工资、医疗、伤残补助、抚恤费用等） | 70%-100% |
| 第二顺位 | 税款和社会保险费用 | 50%-80% |
| 第三顺位 | 普通破产债权 | 3%-30% |
| 劣后 | 惩罚性债权（罚款、罚金等） | 0%-5% |

#### 执行程序中的清偿顺序

根据《民事诉讼法》相关规定：

| 顺位 | 债权类型 | 说明 |
|:---|:---|:---|
| 优先 | 有财产担保债权 | 对特定财产优先受偿 |
| 优先 | 首封债权 | 在执行分配中有一定优势 |
| 普通 | 普通债权 | 按比例分配 |
| 劣后 | 轮候查封债权 | 在首封之后 |

### 1.5 D5 时间价值折扣 — 详细标准

#### 资金占用成本计算

```
时间价值折扣 = 1 / (1 + r)^n

其中：
r = 年化资金成本（通常取5%-10%）
n = 资金占用年数（从判决日至当前日）
```

#### 速查表（按公式 1/(1+r)^n 复算，r=5%–10%）

| 占用年数 n | D5 区间 | 中值 |
|:---|:---|:---|
| 1 年 | 90.9%–95.2% | 93.1% |
| 2 年 | 82.6%–90.7% | 86.7% |
| 3 年 | 75.1%–86.4% | 80.8% |
| 5 年 | 62.1%–78.4% | 70.2% |
| 8 年 | 46.7%–67.7% | 57.2% |
| 10 年 | 38.6%–61.4% | 50.0% |

占用年数为分数时按公式复算（scripts/discount_calculator.py 的 time_value_range 即此实现）。

#### 参考利率

| 情形 | 年化利率 | 说明 |
|:---|:---|:---|
| 保守估计 | 5% | 银行贷款利率 |
| 中性估计 | 8% | 企业加权平均资金成本 |
| 激进估计 | 10% | 小微企业融资成本 |
| 惩罚性估计 | 12%-15% | 包含风险溢价 |

### 1.6 D6 不确定性折扣 — 详细标准

| 不确定因素 | 折扣因子 | 说明 |
|:---|:---|:---|
| 执行进展明确 | 95%-98% | 有明确执行计划和时间表 |
| 执行进展不明 | 85%-95% | 尚未进入执行或信息不公开 |
| 存在法律争议 | 70%-85% | 可能被再审推翻或变更 |
| 时效风险 | 50%-70% | 可能已过执行时效（2年） |
| 债务人下落不明 | 60%-80% | 难以查找财产线索 |
| 政策风险 | 80%-90% | 如央企改革、政府收回土地等 |

## 二、债权信息质量评级标准

### 2.1 综合评级矩阵

| 评级 | 折扣率 | 回收率 | 债权信息特征 | 财务影响 |
|:---|:---|:---|:---|:---|
| A级（优秀） | <20% | >80% | 债务人有充足资产和还款能力 | 无减值风险 |
| B级（良好） | 20%-40% | 60%-80% | 债务人有一定资产，回收存在时间成本 | 轻度减值 |
| C级（一般） | 40%-60% | 40%-60% | 债务人资产不足，需多方追索 | 中度减值 |
| D级（较差） | 60%-80% | 20%-40% | 债务人偿债能力差，回收困难 | 重度减值 |
| E级（极差） | >80% | <20% | 债务人资不抵债或已破产 | 致命减值 |

### 2.2 评级调整因素

| 调整因素 | 上调条件 | 下调条件 |
|:---|:---|:---|
| 优先权 | 有财产担保 | 无优先权 |
| 集中度 | 债权信息分散 | 高度集中 |
| 时效 | 时效充裕 | 存在时效风险 |
| 关联方 | 有强担保方 | 担保方无力 |
| 政策 | 有政策支持 | 政策不利 |

## 三、债权信息集中度评估

### 3.1 HHI指数计算

```
HHI = Σ(债权信息i / 债权信息总额)^2 × 10000

判断标准（与 §3.2 表同一尺度）：
HHI < 1000：低
1000 ≤ HHI < 1500：中
1500 ≤ HHI ≤ 1800：较高
HHI > 1800：高（极度集中）
```

### 3.2 集中度风险

| HHI范围 | 风险等级 | 说明 |
|:---|:---|:---|
| <1000 | 🟢 低 | 债权信息分散，风险可控 |
| 1000-1500 | 🟡 中 | 存在一定集中度 |
| 1500-1800 | 🟠 较高 | 集中度较高 |
| >1800 | 🔴 高 | 极度集中，单一债务人风险突出 |

## 四、债权信息追收策略框架

### 4.1 策略矩阵

| 债权信息状态 | 推荐策略 | 预期效果 |
|:---|:---|:---|
| 已判决、债务人正常 | 协商还款+强制执行 | 回收率约80%（经验估计） |
| 已判决、债务人困难 | 分期还款+资产保全 | 回收率约40%-70%（经验估计） |
| 已判决、债务人破产 | 积极申报债权+参与重整 | 回收率约5%-25%（经验估计） |
| 已判决、失信被执行 | 查找财产线索+追加被执行人 | 回收率约0%-5%（经验估计） |
| 未判决 | 加快诉讼+财产保全 | 视案件情况 |

### 4.2 债权信息转让策略

> 下表折扣为经验估计区间，实际定价以市场询价为准。

| 债权信息类型 | 潜在受让方 | 转让折扣 |
|:---|:---|:---|
| 央企下属企业债权信息 | 央企体系内主体 | 10%-30%（面值） |
| 房地产债权信息 | AMC/不良资产投资机构 | 5%-20%（面值） |
| 关联企业债权信息 | 关联企业其他债权人 | 3%-15%（面值） |
