# Markdown 主文档子集约束与节点映射

> 编写/审改 OTL 主文档时读本件。所有约束同时是 `scripts/otl_source_lint.py` 的裁定依据（括号内为检查编号）。

## 目录

- 骨架标准（文档头六要素 + 变更记录）
- 标题规则
- 正文元素约束
- 节点映射速查
- 不支持/慎用清单

## 骨架标准

每份主文档固定三段式：**H1 标题 → 文档头表 → 正文 → 变更记录**。

```markdown
# 文档标题

| 字段 | 内容 |
|------|------|
| 文档标识 | OTL-XXX-000 |
| 版本 | v0.1.0 |
| 状态 | 草案 |
| 更新日期 | 2026-10-01 |
| 责任席 | （席位/人） |
| 关联锚点 | （技能名/台账位/链接） |

（可选）> AI_READER_NOTICE: 给后续读取本文件的 agent 的一句话指引。

## 正文第一节
...

## 变更记录

| 版本 | 日期 | 变更摘要 | 责任席 |
|------|------|----------|--------|
| v0.1.0 | 2026-10-01 | 初版 | （同文档头） |
```

裁定细则：

- **六要素缺一不可**（E02），字段名恒定、次序恒定；值可为占位但不得留空行。
- **状态词表** ∈ {草案, 现行, 归档}（E03）；状态流转 草案→现行→归档，不逆流，逆流需升版本。
- **更新日期** 一律 `YYYY-MM-DD`（E04）；与内容同步改，禁止只改内容不改日期。模板中的字面占位符 `YYYY-MM-DD` 豁免 E04，实例化时必须改为真实日期。
- **版本语义**：v主.次.修订；结构性变更升次、措辞级升修订；发布到云端后版本只升不降。
- **变更记录**节（`## 变更记录`，亦接受 `## CHANGELOG` / `## 更新记录`）必须存在（E09），每次发布追加一行。
- 发布登记位：文档头表发布后追加两行 `云端 file_id` 与 `云端链接`（lint 对这两行豁免六要素检查之外的格式要求）。

## 标题规则

- **H1 恰好一个**且为首个非空行（E01）：它是文档标题，发布时被提取为 `title`、不进入正文。
- **正文从 H2 起**；层级只许逐级加深（H2→H3→H4…），禁止跳级（H2→H4）（E05）；回退任意级不受限。
- 标题文字不含换行、不含行内图片。

## 正文元素约束

| 元素 | 规则 | 编号 |
|------|------|------|
| 段落/列表/任务列表 | 正常 CommonMark；任务列表 `- [ ]` / `- [x]` 映射为任务列表块 | — |
| 围栏代码块 | ``` 或 ~~~ 必须配对闭合（E08）；语言标签建议注明 | E08 |
| Unicode/ASCII 制表图 | 凡含 ┌ └ ┐ ┘ ─ │ ┼ ═ ║ 等制表字符（U+2500–U+257F）的整段，**必须**整体置于围栏代码块内，语言标签用 `text`/`plain`；裸露在段落/列表中会在 OTL 里错位（E06） | E06 |
| 图片 | `![](src)` 的 src 仅接受 `https://` 公网直链或 `data:` base64 URI；本地相对路径一律报错（E07）；http:// 降级为警告；单张 data: URI 超 10 万字符警告（主文档防膨胀，大底图放项目目录、云端用直链） | E07 |
| 表格 | 简单 GFM 管道表直接写；合并单元格/复杂表发布后用 `block_update` 表格 operation 族处理，主文档中标注「云端合并：起止行列」备查 | — |
| 链接 | 公网链接直接写；内部锚点链接慎用（云端锚语义不同） | — |
| 公式 | 行内/行间 LaTeX 可写（映射 latex 节点），但须客户端可渲染的子集，避免自定义宏 | — |
| 制表符 | 正文中禁用裸 Tab（警告；缩进用列表层级而非空格对齐） | W |
| 长行 | 单行超 300 字符警告（云端阅读与 diff 友好度） | W |

## 节点映射速查

| Markdown | OTL 节点 |
|----------|----------|
| `# 标题`（首个，提取为 title） | `title`（doc 首子块，唯一） |
| `##`–`######` | `heading`（level 1–5，注意 otl heading level 与 md 层级差 1：md H2 通常落为 heading level 1，以实际回读为准） |
| 段落 | `paragraph` |
| 无序/有序/任务列表 | `paragraph` + listAttrs（type 1/2/3） |
| 围栏代码块 | `codeBlock`（仅 codeBlock 内 text 可含换行） |
| 引用块 | `blockQuote` |
| 表格 | `table/tableRow/tableCell` |
| `---` | `hr` |
| 图片 | `picture` |
| LaTeX | `latex` 行内节点 |

> 块级节点的完整类型表（highLightBlock、column、pictureColumn、blockAnchor 等）与属性以 kdocs skill `references/otl/node.md` 为准；这些富节点无 Markdown 对应物，发布后可用块操作补加，并在主文档以注释 `<!-- otl: ... -->` 登记。

## 不支持/慎用清单

- HTML 混排：insert_content 接受 html 格式，但**主文档一律 Markdown**，html 只作一次性转换的临时输入。
- base64 大图：技术上可行，主文档中禁用（防膨胀），见图片规则。
- 目录/封面/高亮块等富组件：Markdown 层不表达，云端补加并在主文档注释登记。
