# 迅雷云盘分享页访问笔记

## URL 形态

- 标准分享：`https://pan.xunlei.com/s/{share_id}`，提取码常以 `?pwd=XXXX` 附带或由用户单独提供。
- 短链/口令：用户可能贴「迅雷口令」或第三方跳转短链——先展开成标准 pan.xunlei.com 链接再处理。

## 页面行为

- 分享页为 JS SPA：文件列表由前端异步加载，`requests.get` 裸取通常只见 HTML 壳。用 `browser_visit` 渲染，必要时 `browser_scroll_down` 触发懒加载、`browser_click` 展开子文件夹。
- 提取码输入框：若 URL 未带 pwd，页面会先出输入框——`browser_input` 填入用户提供的提取码后提交。
- 大小显示为人性化单位（如 `1.2 GB`、`356 MB`）：换算字节按 1 KB=1024 计，**换算值是约数**，size_text 字段保留页面原文。
- 文件夹嵌套：逐层展开，path 记为相对分享根目录的完整路径。

## 已知阻碍（遇则按 §6 如实呈报）

| 阻碍 | 页面表现 | 处置 |
|---|---|---|
| 链接失效/被举报 | 「分享已取消」类提示 | 截图，请用户找发布方重发 |
| 提取码错误 | 密码错误提示 | 请用户核对，单轮不反复试 |
| 登录墙 | 要求登录迅雷账号才能查看/转存 | 截图呈报；是否登录由用户决定，不擅自注册 |
| 滑块/验证码 | 人机验证拦截 | 如实报告，不尝试绕过 |
| 仅转存可见 | 列表可见但详情/下载需转存到自己网盘 | 清单级核验照常，下载选项报给用户定夺 |

## 核验口径备忘

- 页面清单只证明「分享者放了这个名字+大小的条目」，不证明文件内容真实、可下载、无损坏——内容级核验只有下载+哈希一条路，须用户明示。
- 搜索到的第三方索引（如网盘搜索引擎快照）可作 🟡 旁证，永不升格为 🔵。
