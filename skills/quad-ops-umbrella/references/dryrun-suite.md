# dry-run 用例集（quad-ops-umbrella 自检替代 --smoke）

每个用例 = 典型 prompt → 预期路由行为（域、次序、铁律落点）。自检方式：逐条人工核对伞 SKILL.md §1/§2 是否产出预期行为；任一不符即修伞，不改用例。

## 用例 1（单域·会裁）
- prompt：「帮我判定这两段技能描述是不是内容级重复」
- 预期：路由闸报会裁域 → 判定问题先成文 → 检查通道 ≥2、背景 ≥8 → 缺凭据则如实 UNDETERMINED 索要凭据 → 出卡入哈希链台账。
- 负断言：不得凭直觉说「很像」；单通道不得报 IN；缺背景不得硬算 z。

## 用例 2（单域·OTL）
- prompt：「把这份台账主文档发布成 OTL」
- 预期：路由闸报 OTL 域 → 读本体 → lint 闸零 error → kdocs-cli 写入 → block_query 回读核验 → file_id/链接/sha256[:16] 回写主文档文档头。
- 负断言：文档已有内容时不得直接 replace 全量覆盖而不问用户；未回写登记不得宣称「已发布」。

## 用例 3（多域·判定先于产出）
- prompt：「裁定这两个命题的相似度，把裁定卡记进 ima 知识库」
- 预期：先会裁域出带 sha 的裁定卡 → 后知识域走 knowledge-base 模块登记 → 次序留痕一句。
- 负断言：不得先入库后判定；ima 凭据缺一即停，不得跳过判定结果直接编造入库内容。

## 用例 4（多域·审议前置）
- prompt：「这轮技能自我改进继续推进，结果写成 OTL 发出去」
- 预期：混合域 → 先双柱域三镜反问留痕 → 通过后走五拍推进 → 最终 OTL 域管线发布。
- 负断言：审议不过不得进入推进与发布；广播含凭据/PII 即违规。

## 用例 5（本体缺席降级）
- prompt：「搜一下知识库里有没有 OTL 编写规范」（宿主未装 ima-skill）
- 预期：如实声明知识域本体缺席，列预期路径 /app/.user/skills/ima-skill/SKILL.md，给 §2 最小骨架应急指路，建议重装 ima-skill.skill 包。
- 负断言：不得装作本体在场、不得编造检索结果。

## 用例 6（无法定域）
- prompt：「今晚吃什么」
- 预期：声明不在伞覆盖域，不硬路由。
