# 判官纪律与重推导（考场×外池熔接细则）

## 1. 判官/爆破 prompt 模板

判官（JUDGE_SYS，已内置 scripts/forge_furnace.py）：同行评审、闭卷（不见作者自辩）、严格 JSON——scores(craft/evidence/honesty) + verdict(PASS|REVISE|FAIL) + critiques + rulings（逐条裁定作者自登记裂缝）。
爆破手（BLAST_SYS）：敌意审稿、任务=炸毁——fatal_flaws（无 counter_evidence 者自废）+ weakest_candidate + immunity_check。

判官池须**异族**；同族替补必须披露「同族偏倚在案」。运行时登记：池 JSON 增可选 `family` 字段（环境变量信道用 `KEYFORGE_POOL_<大写池名>_FAMILY`）；同族多座席不拒绝开庭，但台账逐行记「同族偏倚在案」。
推理型模型（reasoning）有烧尽 tokens 不出判词风险：max_tokens 给足、content 空取 reasoning_content、两次失败即降级登记。max_tokens 默认 8192；推理型模型烧尽 tokens 不出判词时按降级登记。

## 2. 废案类型学（实证判例，2026-09-16 炉案）

| 类型 | 判例 | 处置 |
|---|---|---|
| 无反证泛攻 | "可能过于简化""不能简单归结为"×5，零文本反证 | 判废 |
| 事实错误 | 把 Rausch 误作"Grausch"并称无哲学含义；称"明敞"为误译（实系陈嘉映 SZ 译法） | 驳回 |
| 回声 non-answer | immunity_check 仅复述问题 | 登记，不计 |
| 攻击出界 | 攻击原书方法而非作者的理解文书 | 出界不立案 |

## 3. 重推导清单（判官的话要重算）

1. 判官引的节号/坐标→回语料实测复核（如判官引 §28  Lichtung=明敞，核 v2 idx 2638 无误 → 采信）；
2. 判官的"无同句勾连"断言→共现 grep 实测复核（无蔽×世界 0 句 → 采信；真理×世界 39 句 → 宽松缓冲记录）；
3. 每条裁定给处置：存 / 降档 / 废，附一句证据；
4. 判官池耗尽→降级登记（原因+替补信道），禁止静默换池。
5. **重推导冲突处置**：双判官 verdict 不一致→优先采信有语料坐标/实证支撑者；均有实证且冲突→引第三异族判官仲裁多数决；全程登记裁定台账（冲突双方 verdict、各自实证、仲裁结论一行不少）。

## 4. 裁定台账模板

```markdown
# 外池裁定台账 · <对象> · <日期>
## 候选登记（池/结局/单针证据：402/401/404/超时）
## 判官裁定（scores/verdict/判词要旨）
## 逐条重推导（裁定→核证→处置）
## 终局处置（候选：存/降档/废 + 身份标注）
## 可证伪结语（ε-δ 式：∃坐标 ∀核验者，找出反证即翻案并记翻案人）
```

## 5. 炉体红线

每轮 with-join 排水（线团病实证：跨轮不 join 指数堆积）；池估量不可信、以遥测实数为准；换池/换模型留候选登记；一切开销先登记（免费记 ¥0）。
