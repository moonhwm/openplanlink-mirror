# 铸造标准 v1.1（矿脉·熔接·金库谱系）

## 1. 矿脉登记表格式

矿脉索引细则（book/chapter/idx 坐标系立法）：

- **book** = 语料唯一标识（含版本/版次，如 `存在与时间v2`、`zaratustra_2024ed`）——同书异版次须分登记，禁混坐；
- **chapter** = 按语料原章节/目录划分（沿用原书章节名/节号，不自造切分）；
- **idx** = 自然句序号（按中英文句读标点切分，自 1 起）——句读标点指 `。！？；.!?;` 等成句符号，子句逗号不断句。
- 完整登记示例：`Lichtung | 存在与时间v2/§28/137 | grep -c=2 | 原词在卷（〔Lichtung〕） | 与"世界"同句 0 句`。

| 词素 | 语料坐标（book/chapter/idx） | 命中次数 | 原词在卷 | 共现实测 |
|---|---|---|---|---|
| Lichtung | 存在与时间 v2 / 正文 / 2638 | 澄明×2、明敞原词双标 | 是（〔Lichtung〕） | — |
| Rausch | zaratustra×2、beiju_dansheng×1、zhaoxia×1、quanli_yizhi_yongheng×1 | 醉脉 383+ | 是（原词 ×5） | — |
| 无蔽×世界 | 释义 | 无蔽×6、世界×2366 | 部分 | 同句 0 句 → 复合无锚 |

三验顺序：频率验（grep -c 实测）→ 原词验（外语原词是否以原文在卷）→ 共现验（复合词素同句勾连）。**各自有据≠复合有据。**

## 2. 身份三档（熔接必标）

- `原义件`：词素即语料原词原义（最高档）；
- `熔接品`：跨文本/跨作者意象熔接——必须写明"非某书原义"，并登记时代滑动区间（例：Lichtung=SZ 明敞（§28 此在展开状态）≠后期林中空地）；
- `血融合件`：语料词素×用户原题——诚实标注哪一半不来自语料。

**「融一词」操作定义**：词素经字符截取/变形/语义转写融合为单个连续无分隔符字符串；禁止两个及以上完整词素并列拼接。
- 正例：`Li`（Lichtung 前 2 字符）+`sch`（Rausch 后 3 字符）+尾缀 `27#` → `Lisch27#`——截取融合，合规；
- 反例：`LichtungRausch`——两个完整词素并列拼接，违规，判废重铸。

## 3. 形态闸门

融一词 / 无连字符 / ≤20 位 / 四类字符齐（大写·小写·数字·符号）/ 尾缀约定由用户定。熵估算：白描多词式按 56 bit 档报；单词熔接式熵低于随机件，须在铸造卡注明"美学件非高熵件，适用账户须配合 2FA"。

## 4. 金库 JSON 谱系格式

```json
{
  "account": "user@example.com",
  "console_password": "<现役，不动>",
  "note": "谱系：vN 批次=来源语料+裁定结论+身份标注；旧版并存不覆盖；服役期与提醒责任人在此注明。",
  "created": "YYYY-MM-DD HH:MM:SS",
  "console_password_<lineage>_a": "<候选a>",
  "console_password_<lineage>_b": "<候选b>"
}
```

- 候选按 lineage 分字段（如 `_heid_a/_heid_b`），新版本只增字段不改旧字段；
- note 记：批次号、词素坐标摘要、外池裁定结论（存/降档/废+理由一句）、身份三档标注；
- 密钥值永不出现于聊天、日志、台账；台账只记"字段名+尾 4 位"；
- 保密边界呼应：候选明文仅入金库，永不进题面/回包引用/日志——呈堂与回包只许铸造卡+矿脉坐标+候选尾 4 指纹。
