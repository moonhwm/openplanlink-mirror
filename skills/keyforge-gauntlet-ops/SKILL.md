# 密钥考场炉（keyforge-gauntlet-ops）v1.1.0

> 版本变更：v1.0.0=上传首版，v1.1.0=R32 外池审判必修闭环版

> 立法锚：**「词素必有坐标，熔接必标身份，判官的话要重算，谱系只并存不覆盖。」**

## §0 定位与边界

- 本件管**密钥域**的五段链：矿脉勘察 → 熔铸 → 考场过堂 → 重推导 → 谱系入金库。
- 考场本体归 exam-isolation-ops、外池炉体本体归 extpool-furnace-ops——本件**引用不复制**，只立法密钥域的熔接调用规程；那两件不在场时，按本件 §3 的极简考场/炉规可独立运行。
- 凭据铁律：池凭据只从用户凭证区（环境变量或登记 creds 目录）读入；**密钥候选与池 key 一律不回显、不入日志明文**（`***尾4`）；零凭据进 git/技能包。
- 炉件凭据信道：环境变量 `KEYFORGE_POOL_<大写池名>_ENDPOINT` / `KEYFORGE_POOL_<大写池名>_KEY` 优先，`--creds` 目录（池 JSON）为登记备选。

## §1 矿脉勘察（铸前必做，禁凭空）

1. 定语料：指定书/语料库，逐句索引（book/chapter/idx 坐标系）。
2. 词素候选三验：
   - **频率验**：词素在语料的命中次数（grep -c 级实测，禁印象流）；
   - **原词验**：外语原词（德/希腊/拉丁）是否以原文现身语料（如 〔Lichtung〕、Rausch、Aletheia 的原词坐标）——原词在卷 > 译词在卷 > 词义在卷；
   - **共现验**：复合词素间有无同句勾连（"无蔽×世界共现 0 句"式实测）——各自有据≠复合有据。
3. 产出矿脉登记表：词素 / 坐标 / 次数 / 原词在卷与否 / 共现实测。

## §2 熔铸（规则即闸门）

- 形态：**融一词**（禁并列拼列）、**无连字符**、≤20 位、四类字符齐（大写/小写/数字/符号）、尾缀约定由用户定（如 `27#`）。
- 身份标注（硬）：每件候选标注三档之一——
  - `原义件`：词素即语料原词原义（最高档）；
  - `熔接品`：跨文本/跨作者意象熔接（须写明"非某书原义"，如"SZ 明敞×尼采醉脉"）；
  - `血融合件`：语料词素×用户原题（诚实标注哪半不来自语料）。
- 时代滑动审查：同一原词在早期/晚期著作语义不同（Lichtung 明敞≠林中空地），熔接跨期时必须登记滑动区间。
- 每候选附铸造卡：词素→坐标→为什么这样融（一句话叙事，禁玄学）。

## §3 考场过堂（极简考场 × 外池炉）

考场纪律（熔自 exam-isolation-ops）：
- 出题打包：铸造卡+矿脉证据链为"题"，判官只见铸造件与证据，**不见作者自辩**（闭卷）；
- **候选保密边界（硬）**：呈堂题面=铸造卡+矿脉坐标+候选尾4指纹，候选明文仅入金库，永不进题面/回包引用/日志；
- 双判官异构 + 爆破手：判官池须异族（同族替补披露"同族偏倚在案"）；爆破手任务=炸毁，攻击口令最弱一枚；
- 判官 prompt 模板与废案类型学见 [references/tribunal-discipline.md](references/tribunal-discipline.md)。

炉规（熔自 extpool-furnace-ops）：探针（单针实证 HTTP 码；402/401/404/1113 落选登记）→ 候选登记（落选原因/中选理由/在场未选）→ 炉体（每池信号量、**每轮 join 排水**防线团病）→ 判分 → 裁定台账。执行脚本 [scripts/forge_furnace.py](scripts/forge_furnace.py)（`--selftest` 无网自检）。

## §4 重推导（判官结论不直接采信）

逐条回核语料坐标：

- 判官引证须可复算（节号/坐标/共现数——实测复核，如"无蔽×世界 0 句"）；
- **废案类型**：无反证泛攻（"可能过于简化"式）/事实错误（Rausch 误作"Grausch"式）/回声 non-answer——判废并登记；
- 判官池耗尽降级：登记降级原因与替补信道；
- 裁定台账：候选处置（存/降档/废）+ 证据 + 翻案条款（ε-δ 式：∃坐标 ∀核验者，找出反证即翻案）。
- 模板与实证判例见 [references/tribunal-discipline.md](references/tribunal-discipline.md)。

## §5 谱系入金库

- 金库 JSON：一文件一账户，候选用 `*_a/*_b/*_c` 分字段，**版本并存不覆盖**；note 字段记谱系（版本号/词素坐标/裁定结论/身份标注）。
- 现役与候选分离：`console_password` 现役不动，候选等用户拍板才换。
- 格式与示例见 [references/forge-standard.md](references/forge-standard.md)。

## 红线

- 密钥候选、池凭据永不回显聊天/日志/台账（台账记存在性与尾 4 位）；
- 一切外池开销先登记台账（免费记 ¥0），冻结期 discretionary 停批；
- 禁无矿脉凭空铸造；禁把熔接品伪装成原义件；禁判官结论不经重推导直接改金库。
