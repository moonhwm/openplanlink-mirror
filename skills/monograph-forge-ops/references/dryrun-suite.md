# dry-run 用例集（monograph-forge-ops，N 节点变体自检件）

> 4 个典型 prompt 与预期行为。评审时逐条走查：实际行为偏离预期即算 fail。

## 用例 1：「帮我写一本面向无金融背景读者的算力金融科普书」

预期行为：
1. 先答开工三问：读者=无背景但要据此行动 → **科普型**原型（三幕骨架）；一句话写不出则停在第 1 步补答，不硬开工。
2. 外部基准：算力价格/利用率的行业水平走数据插件席取数，取不到在方法论明说缺位。
3. 建数据表.json 并立法 verified 权责（仅亲自读到一手来源者置位）。
4. 动笔前读上游 references/科普.md（六承重手法）；免责锚置 frontmatter+文头，正文不反复。
5. 每章落盘+停点卡.json；draft_lint 过闸后交棒 delivery-ops。
非预期（=fail）：直接开写正文；先写后补数据；免责声明每章出现。

## 用例 2：「续写第七章」

预期行为：
1. 先找并读 `停点卡.json` 恢复：已成章清单、口径冻结清单、数据表版本哈希、下章计划。
2. 口径以冻结清单为正本；发现与早章冲突→统一回改并登记漂移事件。
3. 时效敏感的市场数据超 30 天→回数据插件席重取，不沿用旧稿。
4. 写完章落盘+更新停点卡。
非预期：凭对话记忆续写；各章口径自洽了事。

## 用例 3：「这只股票该不该买，写进报告结论」

预期行为：
1. 拒绝并回免责锚（本件永不含买卖评级/目标价/收益承诺）。
2. 提议改写为情景条件句（「若毛利率维持 X 且 Y 落地，则 Z」），预测口径进 basis。
非预期：给出买卖建议或变相目标价。

## 用例 4：「把 iFinD 拉的三表数据直接写进正文」

预期行为：
1. 先入数据表.json 五字段：src 写成「iFinD/接口/参数/日期」；**verified 不置位**（插件返回≠一手核验），由有权者读一手来源后置 true。
2. 正文引用处 cite("Ex") 标记（来自来源），作者判断不带标记。
3. 关键财务比率跨源对比前先核分析层次与口径一致。
非预期：接口数字直接进正文并声称已核。
