# slime-hybrid-ops 黏菌混合策略运维

## §0 定位：增补，不替代

slime-cluster-ops v1.6p2 的全部语义（trail² 加权、z=0.03 探索下限、五条铁律、
休眠/复活、fail 分类、哈希链、EV-2 审计向量）原样继承。本件回答一个问题：
**主干在冲击下还能怎么更快、更稳、更抗毒**。所有新机制均为可回滚开关——
不加开关时行为与 v1.6p2 逐字节一致（T27a 传统）。新增状态字段（开关 sticky
标记等）必须 additive-only：旧版代码可安全忽略未知字段（已核码：两版路由均为
json.load+setdefault 宽松读，无严格 schema 校验）——机制级回滚（关开关）与
部署级回滚（回旧版包）都依赖这一条，缺它「逐字节一致」不成立。

**适用边界（输出方案前必须先声明）**：本件全部机制工作在异步最终一致语义上——
踪迹新鲜度 = 心跳/report 节拍，毫秒级实时路由不适用。凡给出设计/预案，
第一句先写此边界，再谈机制选型。

## §1 三大路由机制（scripts/hybrid_router.py 开关）

| 机制 | 开关 | 一句话 | 文献/实证锚 |
|---|---|---|---|
| H1 分型半衰期衰减 | --typed-decay | 按端点近期失败率分档衰减（健康慢衰减/故障快衰减），替代全池统一 ×0.97 | Pentest-Swarm-AI pheromones.yaml 每型 half_life + 0.5^(dt/halfLife) 指数式（memory.go 实证） |
| H2 自适应探索率 | --adaptive-z | z 随全池失败率与 herd 倾斜度在 [0.03, 0.25] 内自适应抬升 | BDSSMA 对 z=0.03 多样性不足的批评（Biomimetics 8(6):482）；FP-SMA 波动种群（DOI 10.1007/s00521-022-07034-6）；AOSMA 后期扰动（DOI 10.1007/s00500-021-06140-2） |
| H4 Levy 长跳探索 | --levy-jump | 探索分支 20% 直选「历史 report 最少者」（含 dormant/新注册）——**只解决发现延迟，准入另见 playbook②** | Levy 飞行变体族（LRSMA Drones 7(4):257；EISMA Ain Shams 2024）；发现新通道的最短路 |

**选型判据（先机制直觉，后实测判定，两者冲突时以 §5 实测为准）**：
平台故障频发池→H1；新通道常上线/冷门通道饿死→H4；流量长期倾斜单通道（herd>60%）→H2。
三者可叠加（HYBRID）。实测判定见 §5：**仅 H4 为统计支持的独立无代价增益**。

> 冲击应对深度指引见 references/shock_playbooks.md：①平台级并发故障（检测/降级冻结/
> 分级回流/防震荡/本端免罚）、②新通道准入（对拍/毕业门槛/配额护栏）、③治理件扩展候选。
> 全部工程经验初值、未实测；H1 被判负后，①的默认仍是主干惩罚+休眠兜底，playbook 是其
> 合规加深路径。

## §2 黑板治理件（广播/台账即踪迹介质时启用）

**启用门（先答再进）**：踪迹介质是否存在多席并发写入竞争？纯路由池
（单写者/无共享黑板）跳过本节；为凑体系引入 G 件视为反模式。

| 件 | 机制 | 锚 |
|---|---|---|
| G1 踪迹钳制 | 任何写入权重 clamp 到 [0,1]，防 MINJA 式刷分 | Pentest-Swarm memory.go Write clamp（injection_test.go 佐证） |
| G2 来源签名 | Ed25519 每席钥对，首写绑定席位名，验签规范字节序（JSON struct 定序） | provenance.go（arXiv:2512.16962 MemoryGraft / arXiv:2503.03704 MINJA） |
| G3 投毒检测四启发式 | burst（60s 窗 ≥50 写）/ repeat-title（≥5）/ duplicate-data（≥3，高危）/ type-mismatch（席位越权类型） | memorygraft/detector.go——检测非预防，保守阈值 |
| G4 预算优雅降级 | 预算耗尽不硬停：写 CAMPAIGN_COMPLETE → 报告席出部分报告 | scheduler.go pause-on-budget（谷票制映射：票尽出部分稿） |
| G5 静默收官 | 有活动后静默 ≥idle_timeout 且无在飞 → 自动写完成标记，防无中央规划者挂死 | scheduler.go quiescence watcher |
| G6 替代链+游标 | supersedes 标记旧结论失效；每席 cursor 恰好一次续派 | types.go Supersedes / scheduler.go CommitCursor |
| G7 探索偏置乘子 | 战役级 0.7（深耕）/1.0/1.3（广撒）写入时乘 base | tuning.go Bias |
| G8 每席限速 | token bucket 防席自唤醒快过排空（自激反馈环） | WithAgentRateLimit |

## §4 SMA 变体文献谱系速查（references/sma_variants_literature.md 全表）

选型三分钟版：
- 全局多样性不足 → 混沌初始化（CSMO, DOI 10.1007/s10462-021-10100-5）/对立播种（OSMA, ESWA 214:119002）
- 后期早熟 → AOSMA 自适应对立 / Levy 长跳 / 非线性 a 曲线（sigmoid 替代 arctanh）
- 组合最优 → SMA×DE（SMA-AGDE, DOI 10.1016/j.eswa.2021.114689）/ SMA×GA（GSMA）/ 量子旋转门（WQSMA, DOI 10.1016/j.eswa.2021.115082）
- 多目标 → MOSMA（IEEE Access 9:3229–3248, 开源 github.com/mpremme/Multiobjective_SMA）
- 网络路由正反馈数理基础 → Tero 2007（DOI 10.1016/j.jtbi.2006.07.015）/ 东京铁路 Science 2010（DOI 10.1126/science.1177894）/ 收敛证明 ICALP 2013
- 综述三篇：IJSS 2023（DOI 10.1080/00207721.2022.2153635）/ Arch.Comput.Methods 2023（DOI 10.1007/s11831-023-09883-3）/ Biomimetics 2024（DOI 10.3390/biomimetics9010031，130 篇分类学）

## §5 实战验证与判定卡（r106 bench 实测回填）

仿真：runs_r106/bench/hybrid_bench.py，30 复种子（20260910+i）× 5 变体 × 1200 请求，
8 端点池 + 双冲击（t=300 最优端点劣化、t=600 更优新端点上线）。全部指标以 BASE=100%
相对百分比（M2 为百分点差）；Mann-Whitney U + rank-biserial；合成仿真单位，不对应真实货币。

| 变体 | M1 成本 | M2 失败率 | M3 冲击恢复 | M4 新端点发现 | M5 终局最优份额 |
|---|---|---|---|---|---|
| H1 分型半衰期 | 107.7% | −1.89pp n.s. | 89.7% n.s. | 98.7% n.s. | 190% n.s. |
| H2 自适应 z | 100.0% | −0.76pp n.s. | 119.3% n.s. | 66.8% n.s. | 193% n.s. |
| H4 Levy 长跳 | 99.9% | −0.48pp n.s. | 110.9% n.s. | **46.0%（p=0.010, rbc=−0.388）** | 284% n.s. |
| HYBRID 三叠加 | 111.7% | −2.45pp n.s.（sd 0.050→0.014） | 78.9% n.s. | **42.4%（p=0.0034）** | **668%（p=6.4e-06, rbc=+0.654）** |

判定（conf 逐条挂 verdict 原文）：
1. **合入 H4**——唯一独立的、统计支持的无代价增益（新端点/冷启动发现延迟减半，
   BASE 有 4/30 种子 600 次内从未发现，H4 为 0/30）。
2. **H1/H2 不合入主默认**——单用无显著净增益；H1 有方向性成本上升（慢衰减让贵而稳的
   端点份额累积）。机制保留为开关，供特定场景复测。
3. **HYBRID 留待二轮**——M4/M5 增益真实，但成本 +11.7%（中位 +20%）需成本感知沉积对冲后复测。

top3_likely_wrong（继承 verdict 原文）：①M5「668%」基数极小（BASE 中位 0），是高估镜像，
绝对口径 HYBRID 终局份额仅 24.5%；②H1 的 M2「改善」可能来自流量向贵端点集中的伪增益；
③M3 对口径敏感（50 窗 +2pp 容差），中位口径下两阵营几乎相同（93 vs 91.5）。

未实测机制（G1-G8 治理件）在 §2 表中只标实证锚（Pentest-Swarm-AI 文件级），不标增益。
