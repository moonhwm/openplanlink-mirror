# 冲击应对 playbook（shock playbooks）

> 全部为**工程经验初值，未经 r106 bench 实测，不标增益**；阈值需按本池历史回放校准。
> 溯源：r106 swarm 评估 iteration-1 盲比教训（基线臂的通用 SRE 设计在平台故障题上胜过
> 带技能臂的「主干兜底」答法）——本件把该类设计固化为可复用 playbook。
> 与 §5 判定卡的分工：判定卡管「H 系开关合入与否」的实测结论；本件管「冲击来了怎么操作」。

## ① 平台级并发故障（同 --platform 组 2-3 通道同时失效）

- **检测**：同平台组滑窗（10–60s 量级）≥2 通道高失败率且错误类型相似 → 判平台级事件；
  **若存活通道也大面积失败 → 改判本端网络问题，不做任何通道惩罚**（防自我惩罚放大）。
- **降级动作**：故障通道移出选路池（不占 trail² 归一化分母）；幸存通道 trail 冻结
  （暂停衰减与减半，防故障期噪声改写长期记忆）；探测走低频健康检查，不耗业务配额。
- **恢复分级回流，拒绝瞬时全量回切**：半开 → 小权重注入（非恢复历史值）→ 观察窗
  错误率达标 → 50% → 100%；trail 快照持久化，恢复读快照。
- **防震荡**：同通道单位时间熔断 ≥N 次 → 长休眠，仅人工/低峰探测复活。
- **分工声明**（继承 slime-cluster-ops 熔断器范式条款）：熔断器管秒级半开探测，回执走
  report 接口喂回路由层；黏菌管长周期休眠/复活。主干 ×0.5 惩罚 + 休眠兜底是默认**下限**，
  不是上限。

## ② 新通道准入（H4 只解决「发现」，不解决「准入」）

- **probation 态**：新通道默认不进 trail² 竞争池，只走 canary+探索流量。
- **数据质量对拍**：canary 流量与当前最优通道同题对拍（字段完整率/时延/一致性），
  不一致率超阈 → 人工复核，不自动毕业。金融数据池此条不可省。
- **毕业门槛（示例初值）**：累计成功次数、成功率、P95 时延相对池中位倍数、配额余量
  四项全达标才毕业；毕业 trail 不给满值。
- **新人保护**：毕业初期休眠判定窗口放宽（前期样本少防误休眠）。
- **免费通道配额护栏**：独立配额计数，达限置 trail=0 次日重置——防「配额打满→连续
  fail→trail 减半→反复震荡」循环。

## ③ 治理件扩展候选（评估中基线臂实证亮点，本件未覆盖，候选未实测）

- **计分 corroboration**：席位自报权重打折/暂缓，k 席交叉确认才全额沉积——使 burst
  刷分边际收益趋零。
- **蜜罐校验事件**：定期注入已知答案事件，验证限速/去重/确认管线存活。
- **外科手术式回滚**：按事件溯源只剔除违规事件的沉积，不清空通道。
