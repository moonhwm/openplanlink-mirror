# DCC MCP Umbrella（3D 工具线统一封装）

## 定位

Kimi Work 环境里的 3D 能力不是一条线，而是**两大域、七条独立的线**，
账户、授权、工具面完全不同。本技能把它们装进同一个路由框架：
**先探活，再路由，后调用**。

**网格/动画域**（mesh/animation：影视、游戏、AR、3D 打印原型）：

| 线 | 类型 | 授权 | 状态基线 |
|---|---|---|---|
| **Maya** | 插件 MCP（`mcp__plugin-<id>_maya__*`） | 插件安装+本地常驻服务 | 已见注册；服务器可断连，断连时不可调用 |
| **3ds Max** | 插件/本地 MCP（预留位） | 同 DCC 规程 | 当前环境未见注册 |
| **Blender** | 社区 MCP（如 blender-mcp，以实际部署为准） | 本地插件+Socket | 当前环境未见注册 |
| **Rodin**（Hyper3D） | 远端 MCP `https://api.hyper3d.com/api/mcp` | OAuth（浏览器，PKCE S256） | 7 件 `rodin_*` 工具已实测定谳 |
| **Tripo** | 插件 MCP + `TRIPO_API_KEY` | key 在环境 | 24 件 `tripo_*` 工具在册 |

**工程/参数化域**（parametric/engineering：精确尺寸、装配、出图）：

| 线 | 类型 | 授权 | 状态基线 |
|---|---|---|---|
| **SolidWorks** | 预留位（未见知名官方 MCP） | 以实际部署为准 | 当前环境未见注册 |
| **CAD**（AutoCAD 等） | 预留位（未见知名官方 MCP） | 以实际部署为准 | 当前环境未见注册 |

**域纪律**：工程域任务（尺寸链、公差、装配体、工程图）不要路由到网格域
工具线去「凑合」——两域数据模型不同（B-rep/特征树 vs 三角网格），跨域必须
显式说明精度损失。七条线的调用纪律详见 `references/dcc-matrix.md`，
混用是主要事故源。

## 工作流（固定四步）

1. **探活盘点** — 运行 `scripts/probe_dcc.py`：
   - 远端 MCP：给端点 URL，脚本做 initialize + tools/list + 401 挑战解析
   - 插件 MCP（Maya 等）：脚本无法直连时，改走**会话内盘点**——列出当前可见
     工具名，按 `mcp__plugin-<id>_<server>__` 前缀分组（脚本 `--from-list` 模式）
   - 输出统一为 JSON：线名 / 可达性 / 工具清单 / 授权状态 / 失败原因
2. **按任务路由** — 用下方任务词汇表决定走哪条线；目标线不可达时按降级链
   切换并**如实告知用户降级**。
3. **按线调用** — 严格用探活拿到的真实工具名与 schema；任何「猜测的参数名」
   都必须在调用前对照 tools/list 结果核验。
4. **如实回传** — 失败回传原始错误（401/超时/参数拒绝），不包装成成功。

## 任务词汇表（用户说法 → 路由）

| 用户说 | 路由 |
|---|---|
| 「在 Maya/3ds Max/Blender 里打开/改/导出场景」 | 对应 DCC 线；服务器断连→报修复路径（见排错） |
| 「一句话/一张图生成 3D 模型」 | Rodin 线优先（已配 OAuth）；未授权→给授权链接或降级 Tripo |
| 「减面 / 转 FBX / 拆件 / 绑骨 / 贴图」 | Tripo 线（`tripo_convert/decimate/segment/rig/texture` 在册） |
| 「参数化建模 / 工程图 / 装配体 / 尺寸公差」 | 工程域（SolidWorks/CAD 线）；未接入→如实声明，不拿网格域冒充 |
| 「批量生成多个资产」 | 先查配额（`tripo_usage` / Rodin credits），逐件串行，不并发烧 |
| 「这个 3D 工具怎么用 / 连不上」 | 读本技能 + `references/dcc-matrix.md` 排错速查 |

## 红线（绝对）

- **永不编造工具签名**：未见 tools/list 的线，只能给「已注册/未探活」状态，
  调用前必须探活；探活失败就如实说「当前拿不到工具清单」。
- **凭据零落盘**：token/key 只在环境变量或用户指定文件；不进对话回显、
  不进任何交付件。OAuth 全程浏览器，永不代收 API key/密码/验证码。
- **生成即烧配额**：Rodin credits、Tripo 配额都是真钱；查余额是开工闸，
  批量前报数，失败如实传，不盲目重发（防重复扣费）。
- **探活可验证**：宣称「已探活/已盘点」时必须附上脚本关键输出摘要，
  不得空口宣称执行过。
- **同文件编辑严禁并行**；同一生成任务超时不自动重试（先查任务是否已在跑）。

## 文件

- `scripts/probe_dcc.py` — 统一探活：远端 MCP（initialize/tools/list/401 解析）
  + 会话工具清单分组（`--from-list`），输出 JSON 路由表。stdlib only。
- `references/dcc-matrix.md` — 四线对比矩阵、已知工具清单、排错速查、
  新线接入规程。
- `references/playbooks.md` — 典型任务剧本：文生3D、图生3D、DCC 场景批处理、
  格式转换链、国庆视频配 3D 资产等实战流程。
