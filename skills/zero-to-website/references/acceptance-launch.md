# 验收、发布与回滚

按适用范围建立验收矩阵。每项记录：结果（PASS／FAIL／N/A）、实际步骤、证据位置、缺陷与修复提交、复验结果。`N/A` 必须说明理由，不能用未执行冒充通过。

## 目录

1. 功能与运行验收
2. 数据、安全与权限负例
3. 体验、内容与性能
4. 保存和发布的状态边界
5. 域名上线顺序
6. 回滚与交付报告

## 1. 功能与运行验收

- 从干净依赖和冷启动开始构建；记录实际命令与退出码。
- 逐条访问路由，包括直接访问深层链接、刷新、404 和返回路径。
- 在真实浏览器触发首要行动、全部导航和每个可见控件；确认产生可观察结果。
- 验证表单空值、非法格式、边界长度、重复提交、服务端失败与成功反馈。
- 检查空、加载、错误、成功、无权限状态及弹层关闭、Esc、焦点归还。
- 记录控制台异常、资源 404、失败请求；核心流程存在未处理错误时不得交付。

## 2. 数据、安全与权限负例

按实际功能选择：

- **持久化**：写入后刷新、重启服务、换浏览器会话再读；证明数据确实在声明的位置。
- **共享与权限**：使用两个角色或两个用户验证可见范围；尝试越权访问、修改他人 ID、未登录调用 API，必须被拒绝。
- **文件**：上传合法与非法类型、超限文件；回读存储记录并下载核对；确认临时 URL 过期策略和删除行为。
- **密钥**：扫描前端构建产物、仓库、日志、截图和交付文本；不得出现令牌、私钥、会话 Cookie 或连接串。
- **输入安全**：测试脚本注入、HTML 注入、异常 Unicode、路径穿越和超长输入；以实际技术栈补充 CSRF、SSRF、速率限制等检查。
- **隐私**：只收集必要数据，验证删除、导出、同意与第三方请求行为符合已声明策略。

负例应在隔离环境执行，不破坏真实用户数据。

## 3. 体验、内容与性能

- 桌面与适用的移动视口逐页截图并目检；检查横向溢出、遮挡、可读性、触控目标和横竖屏。
- 仅用键盘完成核心流程；焦点可见，动态内容可被辅助技术感知，动画支持 reduced-motion。
- 核对标题、正文、数字、链接、日期、联系信息和法律声明；样例内容必须标明，不得伪造背书或真实事件。
- 检查页面标题、meta description、语义标题、规范链接、站点地图／robots（若适用）和社交分享信息。
- 测量页面重量、请求数、关键资源与主要交互耗时；超出蓝图预算时优化或调整范围并记录。
- 所有外部链接以真实访问结果为准；不因链接存在就声称可用。

## 4. 保存和发布的状态边界

严格区分：

| 状态 | 必要证据 | 不得声称 |
|---|---|---|
| 源码完成 | 文件存在、构建通过 | 可预览或已上线 |
| 版本已保存 | 版本工具成功及版本 ID | 已部署、已有公开 URL |
| 预览可用 | 真实浏览器打开预览并完成主流程 | 公开访问已开启 |
| 部署成功 | 部署工具成功且部署 URL 实测 | 自定义域名已生效 |
| 公开上线 | 公开 URL 实测核心流程 | 所有地区／网络均已验证 |
| 域名生效 | DNS、HTTPS、跳转与页面实测 | 全球传播完成（除非有相应证据） |

只展示工具实际返回或实测获得的 URL；不得猜测、拼接或伪造。

## 5. 域名上线顺序

1. 备份当前版本、数据库与配置，记录原 DNS 和回滚值。
2. 在预发布环境完成全量验收，确认公开内容、法律页面、监测和错误告警。
3. 经授权执行部署；读取部署结果并用真实浏览器验证部署 URL。
4. 经授权修改 DNS；检查解析、TTL、apex／www 与 HTTP→HTTPS。
5. 验证证书链、混合内容、规范 URL、旧链接重定向及公开入口核心流程。
6. 开启监测、备份与告警；观察错误率、延迟和关键转化，不宣称未监测的指标。

任一步失败，停在对应状态并报告最后已知正常入口；不要跳步写成全面上线。

## 6. 回滚与交付报告

发布前明确：

- 回滚单元：网站版本、数据库迁移、对象文件、DNS 各自如何恢复；
- 数据库向前／向后兼容与备份恢复验证；
- 触发条件：核心流程不可用、严重越权、数据损坏、显著性能退化或证书／DNS 错误；
- 回滚后必须重验的页面、API、数据与公开 URL。

最终报告只写事实：交付入口、版本／部署 ID、已实现范围、数据位置、验收证据、未竟项、已知风险、回滚方式及下一动作。保存版本不等于发布；未完成项单独列出，不混入「已完成」。
