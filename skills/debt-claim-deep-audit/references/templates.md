# 输出模板（报告 / 行动清单 / 回收预期）+ 个案示例

## 一、报告结构模板

```markdown
# 债权信息深度核查报告

## 第一部分：债权信息全景
- 债权总额（本金+违约金+利息）/ 性质（普通/优先）/ 形成时间 / 判决调解文书

## 第二部分：债务人财产调查
- 基本信息 / 关联企业 / 家庭关系 / 财产线索

## 第三部分：深挖发现（按轮次）
### 第X轮深挖更新
#### 深挖发现X（重大发现）：XXX规则
- 案例列表（附案号与检索时间）
- 核心裁判规则（附法律依据）
- 适用分析

## 第四部分：行动清单（P0/P1/P2）

## 第五部分：回收预期
- 债权分类 / 回收率区间（含两因子取档理由）/ 损失金额计算
```

## 二、行动清单模板

```markdown
| 优先级 | 行动项 | 前置条件 | 时限 | 说明 |
|:------:|--------|----------|:----:|------|
| P0-0 | 立即联系破产管理人 | 无 | 今天 | 确认重整进展 |
| P0-1 | 立即申报破产债权 | 法院已受理破产申请 | 本周内 | 全额债权（本金+截至受理日利息违约金） |
| P0-2 | 向连带责任人追偿 | 有保证合同/连带责任依据；无则删本项 | 本周内 | 债权全额 |
| P0-3 | 申请调查令调取离婚协议 | 已立案（诉讼或执行中） | 本周内 | 确认财产分割情况 |
| P0-4 | 申请调查令调取关联企业资料 | 已立案 | 本周内 | 确认人格混同情况 |

前置条件未满足的行动项降为 P1 并注明待补条件，不得以 P0 误导用户以为无门槛可执行。
```

## 三、回收预期评估表模板

```markdown
| 债权 | 预估回收率 | 依据（两因子取档） |
|------|:---------:|----------|
| 破产债权 | [x]%-[y]% | [财产净值覆盖率×顺位系数；支持占比缺失时置空并注明] |
| 个人追偿 | [x]%-[y]% | [同上；须先声明连带责任前提成立] |
| 合计 | [x]%-[y]% | 综合评估 |

| 项目 | 预估金额 |
|------|:--------:|
| 债权总额 | [金额] |
| 预计可回收总额 | [金额区间] |
| 预计损失 | [金额区间] |
```

## 四、个案示例（原作者实践档案，仅示格式；数据为特定案件，不得外推）

> 某案（已脱敏）：破产债权回收率估 [低个位数]%（普通债权，回收难度大）；个人追偿 [个位数-十余]%（需发现财产线索）；合计约 [x]%-[y]%。
> 该案债权总额约 XXXX 万元，预计可回收 XX-XXX 万元，预计损失 = 总额 − 可回收（区间端点对应相减，保持勾稽：损失下限=总额−回收上限，损失上限=总额−回收下限）。
> ——原个案金额已按红线移除，本示例仅演示「区间+依据+勾稽」的报告格式；对新案件须按第三部分模板重新计算。
