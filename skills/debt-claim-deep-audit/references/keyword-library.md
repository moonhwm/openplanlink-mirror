# 案例检索词库（三域现成组合）

> 配合 SKILL.md「检索式构造」使用：争议焦点 + 案情特征 + 核心语义标签 三组拼接。

## 配偶财产追索

- 争议焦点：债务人向配偶转移财产、离婚协议财产分割失衡
- 案情特征：无偿转让房产、明显不合理低价转让、离婚后财产分割
- 核心语义标签：撤销债务人向配偶转让财产、强制执行配偶名下财产

## 子女财产追索

- 争议焦点：债务人向子女转移财产、未成年子女名下财产
- 案情特征：房产登记在子女名下、以子女名义购房、向子女账户转账
- 核心语义标签：撤销债务人向子女转让财产、强制执行子女名下财产

## 关联公司利润转移

- 争议焦点：关联公司人格混同、利润转移认定
- 案情特征：明显不合理价格交易、无偿划转资产、虚构交易
- 核心语义标签：认定关联公司人格混同、撤销关联公司不当交易

## 检索目标（goal）写法示例

```
goal: "1. 法院如何认定债务人向配偶转移财产的行为 2. 债权人如何申请撤销"
```

goal 写成编号问题串，便于回收结果时逐条核对覆盖度；每方向检索后登记：实际命中案例数、可用案例数、检索通道、检索时间——这是支持占比样本量的出账凭证。
