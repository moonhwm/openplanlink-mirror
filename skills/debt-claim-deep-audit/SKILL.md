# 债权信息深度核查与执行策略分析

> 方法锚：分轮次、分方向的系统性案例检索 → 裁判规则提炼 → 双轨追偿策略 → 滚动更新的核查报告。
> 红线：凡引用检索支持占比/金额/案例，必须出自当次实际检索并标注样本量；历史参考值仅作先验，不得充当结论。

## 一、工作流（四阶段）

| 阶段 | 动作 | 产出 |
|---|---|---|
| 1 基础信息核查 | 确认债权总额/性质/形成时间/文书；排查债务人身份、关联企业、家庭关系、婚姻变动；初排财产线索（不动产/车辆/股权/知产/存款） | 债权信息全景 + 财产线索初表 |
| 2 多维度深挖 | 按方向目录分轮检索，每轮 3 方向（目录见 references/direction-catalog.md） | 每轮：规则表 + 支持占比 + 适用分析 + 行动建议 |
| 3 策略制定 | 双轨追偿 + 行动清单 P0/P1/P2 分级 + 回收预期评估 | 追偿策略与行动清单 |
| 4 报告整合 | 每轮深挖后滚动更新报告（模板见 references/templates.md） | 核查报告（滚动版） |

### 每轮深挖流程（阶段2的核心循环）

```
1. 案例检索（每方向 8-10 个案例）
2. 裁判规则总结（提炼 5-6 条核心规则，附法律依据）
3. 支持占比统计（支持数/总数，分数报告并标注样本量）
4. 适用分析（规则 × 本案事实 → 结论）
5. 行动建议（可操作清单，并入 P0/P1/P2）
```

## 二、案例检索方法

### 检索式构造

```
关键词组合 = 争议焦点 + 案情特征 + 核心语义标签
示例：
- 争议焦点：债务人向配偶转移财产，债权人能否申请撤销？
- 案情特征：债务人将房产无偿转让给配偶；离婚财产分割明显失衡
- 核心语义标签：撤销债务人向配偶转让财产；强制执行配偶名下财产
```

三域现成词库（配偶/子女/关联公司）见 references/keyword-library.md。

### 案例筛选

- 时间：近 5 年优先；层级：最高法/高院优先；类型：判决书、裁定书；结果：支持/不支持明确
- 每方向 8-10 个，覆盖不同裁判结果，优先说理充分者

### 检索通道（诚实条款）

按部署环境实有通道检索：已挂载的法律案例库（如元典/裁判文书镜像 MCP）、通用 web_search 组合检索皆可。
**原稿所列 `mcp_case_search_case_search` 系作者环境私有通道，并非通用存在**——执行前先确认通道在位；
无专用案例库即用通用检索并如实声明检索域局限，不得假装已检。检索不到足够样本时，如实报告样本量并下调结论强度。

## 三、规则提炼与支持占比铁律

| 环节 | 契约 |
|---|---|
| 规则表 | 每条规则：内容 + 法律依据（条文号），5-6 条/方向 |
| 检索样本支持占比 | 以分数报告（如 6/9），禁一位小数伪精度；**必须标注样本量、检索通道与检索时间；并声明：检索非随机抽样，占比不代表胜诉概率** |
| 适用分析 | 三栏：事实情况 / 规则适用 / 应对策略 |

历史实践参考值（原作者 40 轮深挖样本，本席未独立复核，仅作先验）：配偶财产撤销支持占比约 9/10、子女财产追索约 8/10、关联公司人格混同连带责任约 5/10。**交付报告中引用任何占比，须以当次检索重新统计为准；先验值与当次值并列时须双标注；占比≠胜诉概率≠回收率。**

## 四、策略制定方法

### 双轨追偿

```
轨道一：破产重整中申报债权
- 申报金额：**全额债权 = 本金 + 截至破产受理日已产生的利息、违约金**；时限：法院确定的申报期内
- 依据：《企业破产法》第 46 条——附利息的债权自破产申请受理时起停止计息（受理日后新生利息不计入破产债权）；未到期债权于受理时视为到期；待定债权亦可申报（§47）
轨道二：向连带责任人追偿（**前提：存在连带保证人或其他连带债务人**——先查保证合同/连带责任依据，无则本轨不成立，不得列入行动清单）
- 追偿金额：债权全额（含违约金、利息）
- 依据：《企业破产法》第 92 条第 3 款——债权人对债务人的保证人和其他连带债务人享有的权利，不受重整计划的影响
- 方式：申请强制执行、查封、拍卖
```

### 行动清单分级

| 优先级 | 时限 | 说明 |
|---|---|---|
| P0 | 本周内 | 紧急，立即执行（如联系管理人、申报债权、申请调查令） |
| P1 | 2 周内 | 重要，尽快（如查封财产、调取工商/银行资料） |
| P2 | 1 个月内 | 一般（如评估债权转让可行性） |

### 回收预期评估

```
两步分离（支持占比≠回收率，禁止连乘伪量化）：
第①步 可执行性评估：债务人状态 × 财产线索充分度 → 高/中/低三档
  - 财产线索覆盖率 = 已发现可执行财产估值 / 债权总额（比例，写明估值依据）
  - 执行可行性档（经验档位，先验，须个案说明取档理由）：高 0.6-0.8 / 中 0.3-0.5 / 低 0.1-0.2
第②步 回收率区间 = 财产可执行净值覆盖率 × 清偿顺位系数（按债权性质取档并注明依据）
  - 无检索样本时的降级算法：跳过第①步，直接以第②步财产净值×顺位估区间，报告注明「支持占比缺失」
报告须给区间而非点值，写明每因子取档理由；检索支持占比仅作先验参照，不得充当回收率。
```

## 五、执行策略要点（高频六条）

1. **工资薪金**：可执行，须保留被执行人及其所扶养家属的生活必需费用（具体标准以当地法院口径为准）
2. **住房公积金**：可执行，须符合提取条件，由法院向公积金中心发协助执行通知
3. **商业保险现金价值**：分红/万能/两全型可执行；重疾保障型不宜执行；保险公司有协助义务
4. **养老金**：可执行，须保留基本生活费；未达退休年龄的个人账户资金可执行性各地实践不一，须检索当地裁判口径后个案判断
5. **知识产权**：专利/商标/著作权可查封、评估、拍卖；评估费申请人垫付；流拍率高
6. **股权**：按工商登记冻结拍卖，须通知其他股东行使优先购买权

## 六、输出契约

- 报告结构模板、行动清单模板、回收预期评估表：references/templates.md
- 每轮深挖后：①新增深挖发现章节 ②更新行动清单 ③调整回收预期 ④更新报告日期
- 金额精确到元；检索支持占比以分数报告（如 6/9）并标注样本量；风险用 🔴🟡🟢 分级

## 七、红线

1. 禁编造数据、案例、引文——检索不到就如实说样本不足
2. 检索支持占比/金额必须当次可溯源；先验值仅作先验
3. 检索通道缺位须当轮诚实声明，不得假装已检
4. 个案数据（当事方、金额）入报告前须脱敏或取得授权
