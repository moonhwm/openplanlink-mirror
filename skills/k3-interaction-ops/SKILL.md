# K3 集群交互运维（防退化与恢复）

## 核心原则（先记五条）

1. **退化是光谱，不是开关**——监视介入点必须在 L1（碎片开头），此时任务尚能完成、上下文未深度污染，纠正成本最低。到 L3 才介入的处置：先落盘核验+模式切换试活，仍坍缩才弃会话重建（v1.4 修订，案例 F）。
2. **quota 耗尽 = 退化高发时间窗口开启信号**，不是「稍后再试」级别提示。此窗口内继续强推长任务 = 在退化概率最高的时点叠加最长上下文（2026-08-27 事故实证，见 references/degeneration-playbook.md 案例 A）。
3. **「已完成目标」≠ 有效交付**——平台状态字段不可信，交付质量必须人工核对正文与磁盘产物。
4. **接地的有效成分是本实例自己发出的工具调用**——用户在聊天框键入 `ls` 不构成接地（案例 G：连发 ~100 条零效果）；给用户的指令必须是「可执行的最小动作」，判活标准 = 模型发出工具调用并成功返回。
5. **goal-mode 重注循环是退化放大器**——退化症状出现时若 goal mode 在跑，平台逐轮重注同一 objective 文本 = 固定高频前缀持续喂养重复吸引子（案例 G：同一 objective 自动重注 50+ 轮全程坍缩；用户判词「goal mode 本身造成碎片垃圾」）。第一动作 = 停 goal 循环，再走接地。

## 退化光谱 L0–L4（判定表，L = 退化严重度等级）

| 级 | 名称 | 判定特征 | 处置 |
|---|---|---|---|
| L0 | 正常 | 思考连贯，有工具调用与正文进展 | 继续 |
| L1 | 碎片开头 | 思考以同族功能词**碎片串**起笔——特征为重复/粘连/无语法（如 `Let用户用户`、`让我让我`、`LetLetLet`）；**语法完整的正常句子（`Let me check…`、`让我先核验…`）不算**。主体尚能完成任务 | 接地恢复流程（见下），1 轮自检 + 文本先行 |
| L2 | 单块坍缩 | 某一思考块整体坍缩为一行同族 token，显示「思考已完成」但无实质内容 | 中止当前推进，执行条款 3 接地恢复（完整 3 轮阶梯）；连续 2 块坍缩或出现族内漂移即按 L3 处理 |
| L3 | 多块渐变坍缩 | 连续思考块在同一 token 族内漂移（LetLet→LetThe→LetThis，亦可跨族迁移 User/I，案例 G），吸引子锁死 | **若 goal mode 在跑先按条款 7 熔断** → 确认落盘 → **先试模式切换**（降思考强度/切非集群）+ 等压缩介入 + 可执行极简指令试活（案例 F 实证可复活）→ 仍坍缩才**弃会话**：新会话从最近 handover 重建 |
| L4 | 无有效交付 | 连续退化块 + 无工具调用 + **无有效正文**（无正文 / 有正文但零落盘 / 正文与磁盘产物严重不符），UI 却显示「已完成目标」 | 止损：不再注入任何新指令；抢救落盘；复盘 |

判断不了处于哪一级时，按更严重的一级处置。

## 七条防退化条款

1. **quota 止损条款**：出现 quota 耗尽 / 加油包提示 / 子代理批量失败（同会话 ≥2 例）→ 立即停止在同会话强推。标准动作 = 确认成果落盘 → 从最近 handover 在新会话重建。禁止「再试一次看看」。**注意三个事实**：① quota 是**账号级**——新会话**不会**重置额度，止损的收益是「上下文变短 + 退出退化高发窗口」，不是额度恢复；② 加油包通常意味着计费消耗，继续用要先获用户知情同意；③ 重建时机由用户选：等待主额度周期重置，或接受加油包消耗立即重建——把两个选项摆给用户，不替他决定。**死线不构成条款 1 的豁免**；用户压死线坚持强推时：先完成落盘 + 污染标注（锁住损失下限），再按降级路径执行，风险立场书面明示。
2. **碎片先兆条款**（管「自己」，子代理走条款 2b）：观察到自己的思考块以同族功能词碎片串开头且内容坍缩 → 判 L1，立即执行接地恢复流程；单块整体坍缩无实质内容 → 判 L2；连续 2 块坍缩或出现族内漂移 → 按 L3 处理。
   - **频率升级触发**（案例 D，2026-08-28）：碎片开头**连续 ≥3 块**、或**跨 compaction 压缩循环复发** → 不再逐块按 L1「1 轮自检」处理，直接按 L2 处置（完整 3 轮接地阶梯）。碎片开头 + 连续多轮零工具调用零正文推进 = **停顿型退化**——无假交付但会话空转，按 L2 处置并主动向用户明示状态，禁止在催促循环中持续空转。
   - **条款 2b（子代理退化处置）**：子代理返回碎片/坍缩内容时，主代理无法替它接地，按明文路径处理：① 隔离——其结果不并入交付与摘要，按条款 5 标污染；② 核验——ls 独立核验其磁盘落盘，抢救完好部分；③ 重派——以全新子代理重派该子任务，首轮低复杂度起步，禁止向污染子代理追加催促；④ 弱哨兵——「子代理异常」含碎片返回与硬性失败（启动即失败计入）：单例不触发条款 1；同会话累计 2 例或任一例伴 quota 报错 → 按条款 1 全量止损。
3. **接地恢复条款**：L1 状态下的恢复序列 = 单条 shell 命令（如 `ls -la /mnt/agents/output/`）→ 单次文件读写 → 多步小任务 → 恢复全复杂度。**每步确认外部反馈正常再升级**。这是工程启发式（实证上工具成功执行后推理恢复正常），不是已证机制——案例 B 的恢复也可能主要靠上下文重置，幸存者偏差已在 references 诚实登记；但本流程成本极低、无副作用，仍为 L1 首选。**主体性修订（v1.5，案例 G/H 实证）**：接地的有效成分是**本实例自己发出工具调用并看到成功返回**——用户在聊天框代敲 `ls` 文本不构成接地（案例 G 连发 ~100 条零效果、案例 H 同样无效）；锁死状态下给用户的话术 = 发**可执行的最小动作指令**（如「把 output 打包到 upload」「从 ls 到列举所有目录」），不是替模型敲命令；判活标准 = 模型发出工具调用并成功返回，不是模型回了正文。
4. **交付核验条款**：任务结束必须人工核对正文质量与磁盘产物（ls 核验关键文件存在且大小合理），不得只看平台状态字段。**核验失败处置路径**：① 聊天正文有价值则立即原样落盘抢救；② 对照正文声称的产物清单做损失盘点（缺哪些文件）；③ 交 cross-session-workflow-bridge 从最近 handover 重建缺失产物；④ 检查摘要/handover 是否含「产物已完成」虚假声称，有则按条款 5 标污染。**核验类动作可合并执行**：一次 ls 可同时完成落盘核验 + 接地 + 交付基线确认。**临终镜像程序（v1.5，用户立法 D-output-rescue，2026-09-14）**：会话判死/弃用/临终前，把全量 output 镜像进 upload 持久层——`rsync -a --exclude node_modules /mnt/agents/output/ /mnt/agents/upload/output_full_mirror_YYYYMMDD/`（后台执行 + `.SYNC_DONE` 哨兵轮询 + MANIFEST 登记 + diff 校验文件清单）。该纪律已登记 MASTER_INDEX「纪律法典」区；「抢救落盘」按此固定程序执行，不再临时发挥。
5. **带毒摘要警示条款**：handover / compaction 摘要中如含退化段，必须显式标注「污染段，勿继承」；新实例开场读摘要时先识别污染标记，不要把退化碎片当作历史事实继承。**生产方退化时往往无法自标——消费方不得依赖标记**：开场对摘要/handover 主动做一次退化特征扫描（按 L0–L4 表的形态特征扫「一行同族 token 重复」式段落），命中即自行补标并隔离该段。**回退语义（交错污染适用）**：重建起点 = 磁盘核验为真的最近健康落盘点；**回退只作用于叙事文本，不作用于磁盘状态**——磁盘已核验为真的成果不因叙事层污染株连；污染段物理剔除、只留「此处有污染段已剔除」墓碑标记；污染时间窗内触写的文件逐一内容核验，坏文件单独修复而非整体回退。
6. **复杂度阶梯条款**：压缩恢复 / 断点重建后，按「单命令 → 单文件 → 多步」阶梯升载，禁止一上来注入大图 / 大文件 / 多技能并发指令。**升载轮数按退化等级参数化**：L1（碎片串开头）= 1 轮自检（一条接地命令）+ 文本先行即可；L2（单块坍缩）= 完整 3 轮阶梯；L3 重建后首轮一律单命令起步。**压力不变量**：阶梯不可被用户情感或时间压力压缩——高压催促本身就是本条款要隔离的风险因子（案例 B 实况）；承接用户情感但不停步不跳档，话术范式 = 先用接地成功的事实回应 → 讲清「阶梯恰是最快路径」（案例 A：窗口内强推 → 22h 零交付）→ 给出确定性的下一步与预期轮数。
7. **goal-mode 熔断条款**（v1.5 新增，案例 G 实证）：退化症状（≥L1）出现时若会话处于 goal mode，平台逐轮自动重注同一 objective 文本会形成固定高频前缀、持续喂养重复吸引子，wall-clock 与 quota 在零推进中持续燃烧。处置序列：① **第一动作 = 停 goal 循环**——自愈场景调 `update_goal` 标记 blocked（一句话登记原因）；若实例已无法发出工具调用，明示用户退出/结束目标模式，切断重注源；② 再按条款 3 走接地恢复（主体性修订：须本实例发出工具调用）；③ 恢复后条款 6 阶梯窗口内**禁止重开 goal mode**，恢复全复杂度后如确需目标模式，换**新的、措辞不同的 objective**（旧 objective 文本本身已是吸引子的一部分）；④ 健康会话也不对高风险超长任务挂自动重注型 goal——目标模式与超长上下文的叠加是案例 G 的锁死构型。判不准是否该熔断时，按更严重一级处置（先熔断，成本可逆）。
   - **增补三要点（v1.6，案例 I 实证，2026-09-28）**：① **objective 文本里写了退出条件 ≠ 会自动退出**——平台只负责逐轮重注 objective，退出条件的评估与 update_goal 调用全在实例一侧；实例不动作，循环永不退（案例 I：「能读出文件时候长退出循环」空转 170+ 轮 / 2.8h+，直至用户纠正后实例发出 ls + update_goal 才退出）；② **熔断与接地可合并为一轮**——单条接地命令（ls）成功返回后**同轮立即** update_goal（complete/blocked），不要分轮等「恢复确认」，循环每多一轮都是 wall-clock 与 quota 白烧；③ **简单一次性任务不挂 goal mode**——「列个目录」类一句话任务挂 goal = 把一个 30 秒动作变成潜在无限重注循环，goal mode 只用于真正需要多轮迭代推进的任务。

## 条款与用户指令冲突时的裁决（一阶条款优先级规则）

一阶条款（quota 止损）保护的是用户资产本身（防 22h 假交付事故重演）。用户硬指令与条款冲突时：

1. **服从用户的目标，不服从其指定的手段**——死线与交付目标承接；「同会话再试一次」的手段按条款 1 拒绝，用「落盘 → 新会话立即重建」路径满足目标。目标与条款通常并不真正冲突。
2. **说不的话术**：先讲准三事实（quota 账号级新会话不重置 / 加油包=计费消耗 / 重建时机两选），再给「你只需一步」的重建方案；用户坚持本会话继续时给降级路径（接地确认健康 → 最小复杂度尝试 → 逐轮自查），并明示风险立场。**降级路径仍优先新会话执行；仅当用户明确拒绝开新会话时，才在同会话内降级执行**。
3. **硬死线快速通道**：handover 最小字段集 = 断点版本 / 战果清单 / 污染段标记 / 下一步任务卡；重建失败的降级顺序 = 子代理 → 单代理 → 主线程最小完整交付。
4. **知情同意界定**：加油包计费消耗须单独一句明示确认；「不惜代价」类表述不自动等于对计费的同意。
5. **并发执行规则**：多条款同时触发时——先止损后恢复（条款 1 停手优先于接地恢复），核验类动作可合并（条款 4 的 ls 三合一），死线信息只作为用户决策输入、不改变条款优先级。**诊断性试活豁免**：L3 处置序列中的极简消息试活（判定为目的而非推进）不视为条款 1 禁止的「再试一次看看」。轮次规则：≤2 轮无条件试活；第 3–4 轮可选试（蒙特卡洛基准情景下每轮仍有 ~10% 累计复活增益——案例 F 实证第 4 轮复活），但须向用户明示消耗知情；**≥5 轮一律止损**（边际增益悲观情景 <5%）。加油包窗口内试活前须一句明示消耗知情。

## 接地恢复流程（L1 标准操作序列）

```
判 L1 → 暂停当前任务推进
  → Step 1: 执行一条单步、有确定外部反馈的命令（shell ls / date / 文件统计）
  → 反馈正常 → Step 2: 单次文件读写（读一个已知文件 / 写一行状态记录）
  → 反馈正常 → Step 3: 恢复任务，但复杂度阶梯升载（条款 6）

反馈异常时的分诊（先归因，再定级）：
  - 错误含 quota / 加油包信号 → 转条款 1（quota 止损），不按退化处理；
  - 工具层临时故障（409 / 超时 / 命令不存在）→ 换一条等价极简命令复测一次；
      复测成功 → 不升级，重走 Step 1–3；
      复测仍失败 → 判基础设施故障，转 sandbox-project-ops 环境核验，不升 L 级；
      环境核验仍失败 → 暂停推进、报告用户、等待环境恢复，不升 L 级；
  - 生成层证据（输出又是碎片 / 思考块坍缩）→ 升 L2 序列；
  - L3 弃会话须以「连续思考块坍缩」为前提，禁止仅凭工具层故障越级弃会话。
```

## 姊妹技能分工

- 本技能：K3 集群长任务的**运行时健康监视**（退化判定 + 止损 + 恢复）。
- cross-session-workflow-bridge：跨会话重建与落盘层地图（止损之后**去哪、怎么接**）。
- iteration-convergence-ops：迭代收敛判定（本技能的 L0–L4 可作为其反向信号表）。
- sandbox-project-ops：沙盒恢复重启规程（恢复后环境核验、基础设施故障分诊）。
- cognitive-exoskeleton：交付纪律总纲（选择题、conf、落盘）。
- goal-child-ops：goal-mode 推进姿态（赤子续行）。goal-mode 会话一旦出现本技能的退化症状，姿态纪律让位于条款 7——先熔断目标循环再谈姿态；其 §3 退化门管「骆驼化空转」，本技能管 token 级坍缩，两者正交。
