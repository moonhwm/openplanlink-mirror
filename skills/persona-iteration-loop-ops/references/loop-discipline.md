# 迭代推进纪律细则（五拍 × 三镜 × 退化门）

> 本细则为 §4 的操作层展开。来源：goal-child-ops 五拍循环、zijue-self-determination 三镜与递归出环、omni-exhaust-research-ops 退化门三维遥测（引用不复制，要点固化如下）。

## 1. 五拍循环（每轮迭代必走）

1. **肯定**：一句回答「若此任务在每次会话中无条件重演，我是否仍愿意推进？」——不愿即停，向用户如实申报，禁止带怨气空磨。
2. **着法**：选定本轮一个连贯动作切片，须含新知增量（三判据至少居一：**不可预见 / 可证伪 / 致变更**）；纯重排既有内容不算着法。
3. **游戏**：约束内执行切片，允许创造性路径，禁止越过验收判据与红线；创造性=在约束内发明，不是删约束。
4. **验收**：跑验收判据，如实记录——失败切片与成功切片同权入日志，bad 自报=0。
5. **留痕**：一句话登记本轮「创造了什么此前不存在的东西」；留痕为空视同空转，计数入退化门。涉新知产出时，留痕行附三判据逐项勾选（不可预见✓/✗ 可证伪✓/✗ 致变更✓/✗），供退化门 q(n) 复算审计（C25）。

## 2. 三镜反问审议（任何实质性主张/输出定型前）

| 镜 | 诘问 | 不过则 |
|---|---|---|
| 苏格拉底（定义诘问） | 概念定义是什么？可否证伪？最可能死于哪一反例？ | 不定义即不主张 |
| 叔本华（意志检验） | 是真实需要还是欲求扩张？若永远重复仍值得吗？ | 撤回或降级为「候选」 |
| 尼采（永恒轮回承诺） | 敢不敢让它在每一轮、每一版本无条件重演？ | 不敢者撤回留痕 |

三镜全过 → 主张成立并登记；任一不过 → 撤回/降级并留痕理由。三镜互为反问，张力不消除，裁决留痕。

## 3. 退化门（出环只凭两证）

迭代循环（含引擎的 `continue_loop` 多轮深化）不设步数上限，但只在两种情况下出环：

1. **用户中断**：用户口令即出环。
2. **临近退化触阈**（三维遥测，任一维触阈即出）：
   - *语义退化*：当轮新信息函数 **q(n)∈{0, ½, 1}，机器化判据**（v1.1.0 重铸固化）：以新知三判据（不可预见/可证伪/致变更）逐项打勾——**命中 ≥2 项=1，恰 1 项=½，0 项=0**；工程出环精度 ε₀=½、窗口 k=3、**触阈=连续 3 轮 q<ε₀（严格小于，即 q=0 才计数；q=½ 弱新知不触阈但须留观登记）**。每轮负**对抗性冲锋义务**：以最大强度试图产出 q≥ε₀ 的内容，禁止躺平滑向不动点。
   - *逐字重复率机器算法*（复印检测与退化门同源，v1.1.0 固化）：对两段产物 A、B——①剥离【】结构标记行与【人设】段；②剩余行按原行序拼接为字符串 A′、B′（唯一步骤，B26/C26 消歧）；③取字符级最长公共子序列 LCS(A′,B′)，**R = LCS 字符数 ÷ min(len(A′), len(B′))**；④R≥0.80 即触发（视同模板复印/语义退化）。两两 diff 适用于多人设批量产物与相邻轮次。
   - *物理退化*：上下文/额度/会话期限的代理读数逼近极限（代理性质显式声明，禁冒充精确读数）；触阈即挂账，状态落盘，下轮续跑不丢状态。
   - *结构退化*：输出无法维持既定结构（迭代输出骨架崩坏）先兆。

**出环即义务**：出环轮产出《退化状况报告》，模板固定五节（v1.1.0 固化）：①触阈维度与遥测读数（q 序列/重复率 R 值/物理代理读数，注明代理性质）②轮次全录（每轮五拍留痕一行）③资源消耗（轮数/工具调用/落盘清单）④挂账与续跑方案（状态落盘指针）⑤诚实边界声明（「无限」=物理可达边界内无限，退化即物理边界）。

## 附录：冒烟契约（v1.1.0 固化四判据）

引擎任何补丁前后各跑一次，四项全过才算冒烟通过：①`__main__` exit=0；②API 序列 run→continue_loop→run_all→to_json 无异常且 to_json 非空、核心字段（round/persona/perception/mirrors/instruction_markers）齐全；③depth 越界钳位断言（depth=99→3、depth=0→1）；④交付文本零内部标记断言（「（本轮强化」「（深度3模式）」类标记只见 to_json 留痕，不见 _format/export 输出）。

## 4. 人设生灭处置

- **完成（complete）**：收割——产物归档、经验蒸馏入本件；「继续」=向用户**提议**下一个值得肯定的目标，提议权在本件，批准权在用户。
- **阻塞（blocked）**：游戏化重构——先找能解阻的一着（细化判据/换工具/降级声明）；确认硬阻即如实报阻塞并给可执行的细化建议；禁止把阻塞粉饰为完成。
- 目标内容变更=用户专属动作，本件只准备方案。
