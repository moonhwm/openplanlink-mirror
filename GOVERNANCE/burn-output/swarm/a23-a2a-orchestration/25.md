# 多裁判合议与投票

## 一、从独任到合议

单一裁判的裁决质量受三个不确定因素支配:裁判当次的采样随机性、裁判个体的系统性偏置、标准边界的解释分歧。合议制(multi-judge panel)用多个独立裁判替代独任,把这三类不确定分别转化为可观测、可对冲的信号:采样随机性被多数决平滑,个体偏置在分歧中暴露,边界分歧上升为显式争议件。

合议的成本是裁判费乘以席位数,因此适用面天然受限:高风险产物、争议标的大的裁决、独任裁判校准不达标的场景。低风险批量裁决用独任加抽检更经济。

## 二、三种表决规则

- **多数决**:得票过半即通过,容错性好,但对"接近半数的反对"不敏感,少数派的重大异议可能被淹没;
- **一致决**:全票才通过,零容忍错误放行,但任何一个偏严裁判都能卡住流程,吞吐最低;
- **分级多数**:关键裁决(放行、定责)要求三分之二多数,常规裁决过半即可,按后果严重性配置表决强度。

## 三、合议的参考流程

```python
def panel_verdict(dispute, judges):
    verdicts = [j.judge(shuffle_for(j, dispute)) for j in judges]
    # 每位裁判拿到顺序随机化后的争议件,抑制位置偏置
    tally = collections.Counter(v.chosen for v in verdicts)
    top, votes = tally.most_common(1)[0]
    ratio = votes / len(judges)
    if ratio >= TWO_THIRDS:
        return Verdict(top, basis=merge_basis(verdicts),
                       dissent=collect_dissent(verdicts, top))
    return escalate(dispute, verdicts)   # 未达门槛,升级处理
```

两个工程细节:每位裁判独立拿到随机化顺序的争议件,防止顺序效应全体同向;少数意见(dissent)不随裁决丢弃,进档案供升级与复盘。

## 四、分歧的黄金价值

合议的分歧不是麻烦,是免费的质量信号。按分歧形态分诊:

1. **均分僵局**:票数接近,说明争议件处于标准边界——正确动作是把该边界情形沉淀为新判例,补进标尺锚点,而不是反复重裁;
2. **单票离群**:某裁判长期与其他人相左,统计其离群率,持续离群者复训或撤席;
3. **高置信冲突**:两位裁判都高置信但结论相反,提示证据集不完备,退回补证而非硬裁。

## 五、裁判席的构成原则

- **独立性**:席间裁判不得共享上下文或互相通信,背靠背独立裁决后才亮票,防止从众;
- **异构性**:席位尽量跨模型家族、跨评分风格,同构合议只是昂贵地重复同一个偏置;
- **规模奇数**:三、五、七席,避免天然平局;
- **动态席次**:按争议标的配置席数,小争议三席,重大争议五席起步,席数与代价挂钩。

## 六、成本控制

合议的成本优化三板斧:分层——只有独任置信度低的裁决才升级合议;部分合议——对多数决场景用"独任先裁、随机抽席复核"替代全员表决;异步并行——各席并行裁决不串行排队。合议率(升级到合议的裁决占比)是核心监控指标,合议率持续偏高说明独任裁判的校准出了问题,根因在独任而非合议。

## 七、合议的可信度验收

一套合议机制是否可信,用两个统计验收:与人工金标的一致率(合议结论对标人工标注的准确度)、席间一致率(裁判彼此的吻合程度)。席间一致率过高(近乎全同)提示异构性失败,合议退化为花钱买重复;过低提示标准混乱,分歧大于信息。两个指标联合落在合理区间,合议才算物有所值。
