# code技能：ArkTS适老化UI设计——大字白话卡片流规范

> 编写时间：2026-09-23
> 编写席位：Moon席位批次写手-B组-1号（GLM-5.3-Flash）
> 适用范围：harmony-app（铃语）端侧所有页面的视觉与交互设计实现
> 事实来源：字号与布局取自 `entry/src/main/ets/pages/Index.ets:51-91`（字体/间距 getter），色板取自 `entry/src/main/ets/services/SettingsService.ets:46-66`，演示卡与空态取自 `Index.ets:13-23,430-443`。

## 0. 五条设计原则（不可逾越约束的展开）

铃语服务的是看行情、听播报的老年用户，UI 的全部裁决标准收敛为五句话：

1. **看得清**：主信息 28-34fp 大字起步，大字档标题上探 40fp；辅助信息可降但绝不挤进主信息区；
2. **听得懂**：一律白话句子，说人话不说术语，数字带单位带对比；
3. **点得到**：可点目标热区不小于 48vp，整卡可点，按钮带文字不玩纯图标；
4. **不吓人**：高对比但不刺眼，夜间模式默认，异常状态用平实文案不弹窗轰炸；
5. **不空白**：首屏永远有内容——服务未连通就显示带「示例」字样的演示卡（硬约束）。

另有两条红线与 UI 直接相关：**禁K线图等复杂图表**（一切趋势用文字+方向徽章表达）；**文案三禁**——不承诺收益/保本、不输出催促性指令、不涉对外公开/收费。

## 1. 字体阶梯规范

字号不是拍脑袋，是两档 × 七元素的固定矩阵（实现见 `Index.ets:51-71` 的 getter，`fontLevel` 为 `'standard' | 'large'`，类型定义在 `SettingsService.ets:30`）：

| 元素 | standard 档 | large 档 | 说明 |
| --- | --- | --- | --- |
| 页面标题「铃语」 | 34fp | 40fp | Bold |
| 卡片标题（股名/涨跌徽章） | 30fp | 34fp | Bold |
| 一句话结论 headline | 28fp | 34fp | **主信息，适老化基准字号带** |
| 补充事实 detail | 22fp | 26fp | 次要信息，仅辅助 |
| 状态行/时间 | 20fp | 24fp | 最小字号下限 |
| 播报按钮「▶ 听 / ■ 停」 | 28fp | 32fp | Bold，金色 |
| 徽章「自家信号」 | 18fp | 20fp | 唯一允许低于 20fp 的元素，非关键信息 |

规范条文：

- **28-34fp 是 headline/卡片标题的法定区间**，large 档整体右移；任何新增正文元素默认落在此区间；
- 20fp 为全应用硬下限（徽章例外且仅限非关键标识），低于下限的"设计稿美感需求"一律驳回；
- 字号档与适老化模式联动：开启适老化自动设 large 档，关闭恢复 standard（`SettingsService.ets:184-196` 的 `setElderlyMode` 内联动写入）；
- 用 getter 集中管理（`titleSize`/`headlineSize`/...），**禁止在布局里散落魔法数字**，换档只改一处；
- 长股名 `maxLines(1)` + `textOverflow(Ellipsis)`（`Index.ets:378-380`），但 headline 不截断、允许换行——结论必须完整可读。

## 2. 高对比配色规范

双主题色板固化为 `ThemeColors` 接口（`SettingsService.ets:36-44`），两组常量（46-66 行）：

| 语义槽位 | 夜间 NIGHT_COLORS | 白天 DAY_COLORS | 用途 |
| --- | --- | --- | --- |
| pageBackground | `#0d1117` | `#f5f7fa` | 页面底 |
| cardBackground | `#1c2433` | `#ffffff` | 卡片面 |
| textPrimary | `#e8edf5` | `#1d2129` | 主文字 |
| textSecondary | `#c6ceda` | `#86909c` | 次文字 |
| accentGold | `#f0b232` | `#d4951a` | 强调/播报钮/设置入口 |
| riseRed | `#e74c3c` | `#cf0a2c` | 涨 |
| fallGreen | `#2ecc71` | `#00b42a` | 跌 |

规范条文：

- **涨红跌绿**遵循 A 股心智，方向徽章以色块+单字「涨/跌/平」双通道表达（`Index.ets:366-372`，`dirColor`/`dirLabel` 见 289-307 行）——色弱用户靠字、色觉正常用户靠色，互为冗余；
- 对比度底线：主文字对卡面不低于 7:1 量级（`#e8edf5` 对 `#1c2433` 远超 WCAG AAA），次文字不低于 4.5:1；夜间模式为**默认值**（`themeMode` 默认 `'night'`，`Index.ets:39`），老年人常见白内障畏强光，暗底更舒适；
- 自动主题：`autoThemeEnabled` 默认开，按时间计算昼夜（`Index.ets:123-128` 调 `computeAutoThemeMode`），手动选择则尊重用户；
- 金色只用于"可操作/需注意"（播报钮、设置入口、免打扰标识、未读圆点），**红色只用于涨与错误提示**（`Index.ets:412-416` 的「语音加载失败，点重试」也用 riseRed），语义色不挪用；
- 颜色一律经 `this.theme` 动态取（`Index.ets:94-96`），禁止页面内写死色值——写死会导致主题切换漏改。

## 3. 卡片流布局规范

结构：`List({ space: cardSpace })` + `ForEach` 以 `alertId` 为键（`Index.ets:355-356,425`）。规范：

- **间距三档**（`Index.ets:74-91`）：适老化模式卡间距 20/内距 20/卡内元素距 12，非适老化 12/16/8——间距随模式缩放，密度让位于辨识；
- **整卡可点**：`onClick` 挂在卡片 Column 根上（`Index.ets:423`），点哪都能播，不要求精确点击小按钮；卡片圆角 16、`width('100%')`，单列铺满不做多列网格；
- **卡片信息四行制**：①方向徽章+股名+「自家信号」徽章+播报钮；②headline 结论；③detail 补充（空则不占位，`Index.ets:405-410`）；④失败提示（仅失败时出现）。四行讲完一条异动，不加第五行；
- **未读标识**用 10vp 金色圆点（`Index.ets:361-365`），不用角标数字（数字带来"必须清零"焦虑，违背"不吓人"）；
- List 占满剩余空间 `layoutWeight(1)`（428 行），顶栏固定，滚动只在卡片区；
- `ForEach` 键必须唯一稳定（alertId），保证刷新时只重绘变化卡片，不整列闪动。

## 4. 白话文案规范

headline 是产品灵魂，句式规范：

- **一句话说结论**，主谓齐全，如现网示例卡「中国巨石 2 分钟上涨 2.3%」（`Index.ets:20`）；
- **数字带尺度**：不说「波动异常」，说「2 分钟涨了 2.3%」；时间、幅度、价位齐全（detail 补量能与价位）；
- **禁术语**：不出现「均线金叉」「放量突破平台」「MACD 背离」类黑话；方向只用涨/跌/平三字；
- **三禁的 UI 落地**：headline/detail 只陈述已发生的事实，不出现「买入」「加仓」「马上」「最后机会」等催促词，不出现收益承诺；`kind === 'signal'` 的自家策略解读用「自家信号」徽章明示来源（`Index.ets:381-389`），且不出现公开/收费话术；
- 示例数据必须带「示例」字样（`Index.ets:21` 的「示例数据，服务器接通后自动换成真实异动」），演示与真实永远可区分，杜绝误导。

## 5. 首屏永不空白与异常态

四态设计（全部现网已实现）：

1. **未连通/首帧**：`items` 初始即 `DEMO_ITEMS`（`Index.ets:13-23,28`），带示例字样演示卡，用户打开即见完整形态；
2. **连通但无异动**：空态居中「今日暂无异动」+「监测进行中，有新情况会自动推送」（`Index.ets:430-443`），不用空白也不用旋转菊花；
3. **连接中断**：连续 2 次失败置 `connectionBroken`，顶栏平实提示「连接中断，显示旧数据」（`Index.ets:335-339`），**保留旧数据不清屏**；
4. **限流**：429 静默跳过，不打扰用户（`AlertPoller.ets:44-49`）。

异常态一律**行内平实文字**，禁止模态弹窗与感叹号图标——老人对弹窗的普遍反应是恐慌性关 App。

## 6. 触控与热区规范

- 可点文字按钮加 padding 把热区撑到 ≥48vp：设置入口 `padding({left:12,right:12,top:10,bottom:10})` + `constraintSize({minWidth:48, minHeight:48})`（`Index.ets:346-347`）；
- **按钮即文字**：「▶ 听」「■ 停」「设置」全部文字化（391-392 行），零图片资源、零三方图标库，符合零三方依赖约束；符号▶■随字号放大；
- 播报钮三态显文：加载中「…」、播放中「■ 停」、空闲「▶ 听」（`Index.ets:391-392`），状态可读不靠猜测；
- 不依赖长按、双击、滑动手势完成核心操作；返回导航用系统手势 + Navigation 栈（`Index.ets:310,449-456`）；
- 顶栏状态位（播报关/免打扰/刷新时刻）用文字徽章（`Index.ets:318-339`），色彩语义化：播报关用红（提醒注意）、免打扰用金。

## 7. 反模式清单（评审即否决）

- [ ] 出现 K 线/分时/技术指标图（铁律）；
- [ ] 正文元素低于 20fp、或 headline 落在 28-34fp 区间外（large 档 34fp 顶格）；
- [ ] 布局里写死色值/字号，绕开 `theme` 与字体 getter；
- [ ] 纯图标无文字按钮、热区 < 48vp；
- [ ] 首屏任何时刻空白/白屏/无内容骨架；
- [ ] 弹窗式报错、感叹号恐吓文案；
- [ ] 文案含收益承诺、催促指令、公开收费话术；
- [ ] 示例数据不带「示例」字样混入真实流。
