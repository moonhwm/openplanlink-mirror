# 技能：交接协议

> 所属：GOVERNANCE/skills/governance/ ｜ 版本：v1.0 ｜ 日期：2026-09-23 ｜ 适用项目：harmony-app（代号铃语，鸿蒙适老化股票异动播报应用）

## 一、目的与适用场景

席位交接（Moon 更替、工程角色换人、长期中断后恢复、席位扩编）是知识资产流失风险最高的时刻：对话记忆不可迁移，聊天记录不可检索，未落盘的"潜规则"随人消失。本协议用"分级材料清单 + 固定阅读顺序 + 验收自检"把交接变成可核查的流程，而非一次聊天。

适用场景：任何形式的接任者进入工程；交出方离场前的收尾；恢复一个搁置已久的会话或工程分支。

## 二、交接三原则

1. 文档优先于记忆：一切交接以落盘文档为唯一媒介，口头与聊天内容仅作导航，不作为事实来源；
2. 顺序阅读：材料按第四章顺序读，跳读等于漏读；
3. 验收自检：接手者必须通过第五章自检清单才算交接完成，"我大致看过了"不算通过。

## 四、阅读顺序与理由

固定顺序：**总纲 → 已知问题 → 时间线 → 技能 → 代码**。

理由：先读总纲，知道什么不能碰（红线与约束先行，防止上手第一件事就越界）；再读已知问题，知道现在哪里是坏的（避免把已知缺陷当新发现重复排查）；再倒序读时间线，知道缺陷是怎么来的、为什么那样处置；然后读技能，掌握既定打法，避免重新发明流程；最后带着以上全部背景读代码，此时每一行代码都有语境，效率最高。

最大反模式是把顺序倒过来：一上来读代码，一周后仍分不清哪些是占位、哪些是降级、哪些不能动。

## 五、接手验收自检（10 问）

接手者须能不查资料闭卷回答以下问题；答不出 ≥2 题回到 P0 补读后再验：

1. 三条内容红线是什么？各自边界？
2. 适老化的字体与文案硬约束是什么（fp 范围、卡片流、禁哪些图表）？
3. 首屏永不空白如何兜底？演示卡必须带什么字样？
4. 当前数据源是谁？为什么？恢复 Tushare 需要什么？
5. alerts.json 里 audioUrl 为 undefined 时端侧行为是什么？
6. PushService 现状与目标链路分别是什么？
7. Stage 模型下本项目的 SDK 版本与依赖约束是什么？
8. CHANGELOG 五要素是哪五项？
9. 什么情形必须触发 24 小时实验安全阀？
10. 接手第一个 24 小时允许做什么、禁止做什么？

## 六、交接期行为约束（接手者首个 24 小时）

1. 只读观察：允许读文档、读代码、跑构建、看日志；禁止修改代码与配置（活跃事故处置除外，且处置后立即按 changelog-format.md 补条目）；
2. 不推翻架构基调：EntryAbility、Index 卡片流、AudioPlayer、AlertFeed 契约视为不可变基线，改造提案先落文档再议；
3. 不泄露凭据：文档、日志、代码注释、对话中均不得出现 Token/密钥原文；
4. 全程带标签：交接期所有动作在 CHANGELOG 中以 `[交接期]` 阶段标签 + `#handover` 标签记录。

## 七、交接双方职责与收尾动作

交出方收尾五动作：

1. 按第三章清单逐项核对材料在位且为最新版本；
2. 未完成事项逐条落入 CHANGELOG 条目的"遗留什么"，不留口头账；
3. KNOWN-ISSUES.md 更新到当前真实状态；
4. 技能索引指向有效（失效技能标注待修订）；
5. 追加最后一条条目：`[时间] [原席位] [交接期] 交接完成，接任者为 <席位标识> #handover`。

接手方收尾三动作：

1. 完成第五章自检，把答题结果（含答错的与补读记录）追加为 CHANGELOG 条目，WHO 写新席位、阶段写交接期；
2. 首个自主任务完成后执行一次完整学习闭环（learning-loop.md 五步）；
3. 首周内对任一技能文档执行一次冷启动验证（skill-doc-format.md 第四章），结果回填技能修订。

## 八、反模式

1. 口头交接：靠聊天与记忆，文档零更新，两周后知识归零；
2. 全量倾倒：把仓库所有文件扔给接手者"自己看"，无分级无顺序，红线最容易被漏；
3. 带病交接：已知问题不登记就让接手者接盘，接手者把已知缺陷当新发现重复排查；
4. 越权热身：接手第一天就重构，违反只读约束与架构基调；
5. 自检走过场：10 问抄文档作答，未真正闭卷。

### 自我评估
- 正确性：4分 材料清单与验收问题全部锚定项目共享事实（架构基调、已知问题、约束、既有技能路径），Stage 默认路径已注明"以实际为准"；README/KNOWN-ISSUES 等治理配套文件若未建立，已有明确的登记指引。
- 完整性：4分 覆盖清单、顺序、自检、行为约束、双方职责与反模式；未含多席位并行交接的冲突处理。
- 可复用性：5分 分级表格与 10 问清单可直接执行，交出/接手双方动作各自成列，可打勾验收。
- 字数：约3000字
